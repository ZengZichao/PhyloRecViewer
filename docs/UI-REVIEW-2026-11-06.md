## 一、发现并修复的问题（13 项）

### P0 — 界面元素互相遮挡（信息不可读/不可达）

**F1 · 对比视图底部状态栏叠压画布提示条**
`src/styles.css` `.compare-status`。状态栏原为 `position: absolute; bottom: 0` 的覆盖层，
压在下方窗格 `.canvas-hint`（`bottom: 12px`）之上；半透明底（92% panel mix）让两层
文字互相透出（"Shift"、"Click a species branch to mirror it" 幽灵字），窄窗（1024/1280）
下状态栏换行后更把提示条完全盖住。
**修复**：状态栏改为流内元素——对比分支外包 `.split-outer`（flex column），状态栏成为
窗格行的**兄弟节点**，两种分栏方向下窗格都让出高度，永不再叠压。

**F2 · 分屏窗格标题被浮动工具栏遮挡**
`src/styles.css` `.pane-label`。标题芯片居中 `top: 12px`，与左上角工具栏（top 16、
高约 42、宽约 330–460px）在同一水平带；窗格略窄时标题整个滑入工具栏下方
（1280×800 对比视图中两个窗格标题完全不可见，仅露出 "…son"、"...cation-rich)" 的残段）。
**修复**：标题移到工具栏下方（`top: 64px`），并加 `max-width: min(60%, calc(100% - 48px))`
+ 省略号，长文件名不再可能撞上小地图。

**F3 · 导出菜单文字截断/中段裁剪**
`src/styles.css` `.menu-scale`（grid，`grid-auto-flow: column; grid-auto-columns: 1fr`）。
菜单宽度容不下六个 1fr 列时：`.menu-scale-btn`（ellipsis + nowrap）把四个格式按钮统一
裁成 "Export…"，格式名（PNG/SVG/PDF/HTML）完全丢失；`.menu-scale .menu-item`
（`justify-content: center` + overflow hidden）把标签从**中段**裁断——
"Screen 2× (192 DPI)" 显示为 "n 2×("、"Theme background" 显示为 "eme backgro"，
首尾同时缺字，中英两版一致复现。
**修复**：`.menu-scale` 改为 `display: flex; flex-wrap: wrap`，芯片按内容自适应宽度
（`flex: 0 1 auto`、`padding: 4px 10px`），放不下自动换行；所有标签完整可读
（Export PNG / Screen 2× (192 DPI) / Theme background …）。

### P1 — 布局碰撞与可达性

**F4 · 偏好设置按钮省略截断**
`src/styles.css` `.settings-row .btn`。固定 132px 轨道 + `nowrap + ellipsis` 把
"Screen 2× (192 DPI)" 裁成 "Screen 2× (19…"、"Set as default view" → "Set as defau…"、
"Clear autosave data" → "Clear autosave d…"、"Reset preferences" → "Reset prefere…"。
**修复**：允许两行换行（`white-space: normal`），保留固定轨道宽，组内仍对齐。

**F5 · 1024×768 三层叠压（图例 × 统计胶囊 × 提示条）与面板启动策略**
`src/app/App.tsx` 窄窗口启动阈值（原 1000/820）在 1024 宽下**双面板全开**，
画布仅剩约 470px，图例（≤220px）、统计胶囊、提示条三者在底部互相叠压。
两处修复：
- 阈值调整为 `w < 1180` 收起分析面板、`w < 920` 收起侧栏，保证 ≥700px 画布；
- `.canvas-hint` `max-width` 70%→60%，`.legend` 加 `max-height: calc(100% - 96px)`。

**F6 · 演示模式恢复逻辑吞掉窄窗口面板策略**
`src/app/App.tsx` 演示模式 effect 的 else 分支在**首次挂载时也会执行**：
`prevPanelState` 初始值为 `{sidebar: true, panel: true}`，挂载即把窄窗口刚收起的
面板重新打开——旧阈值（1000/820）下同样存在，只是从未触发过。
**修复**：增加 `wasPresenting` ref，仅在 presenting→false 的**转换**时恢复面板。

**F7 · 节点检查器锚定视口而非画布区**
`src/app/App.tsx`。`<NodeInspector/>` 渲染在应用根；`.node-inspector` 为
`absolute; left: 12px; bottom: 34px`，最近定位祖先是视口——卡片盖住**侧栏**
的样式/标签分区控件（双面板全开时不可点）。
**修复**：移动 JSX 至 `<main>` 内（`.main` 已是 `position: relative`），卡片停靠画布左下。

**F8 · 小地图与浮动工具栏碰撞**
`src/styles.css` `.minimap`。`top: 16px` 与工具栏（top 16、宽可达 460px）同带；
窄画布（对比并排窗格 ~480px）下工具栏尾部按钮被小地图盖住。
**修复**：小地图 `top: 64px`（工具栏之下），与标题芯片同带但分居两侧，互不接触。

**F9 · 演示模式退出按钮压住菜单栏**
`src/styles.css` `.exit-presentation`。`fixed; top: 10px; right: 12px` 正好叠在
菜单栏的 "Preferences / Help" 上。
**修复**：改 `bottom: 14px; left: 50%; translateX(-50%)` 底部居中。

**F10 · 快捷键帮助"交互"区文案重复/错配**
`src/app/HelpOverlay.tsx`。kbd 键位列里塞整句手势描述且与右列完全重复
（"Click a species branch to mirror it | Click a species branch to mirror it"、
"Rename label | Rename label"），⟳/⇠ 一行与下方"鼠标与触控"提示重复，
"Click empty space to clear" 行的标签却是 Esc 的语义（Close panel）。
**修复**：重写 gestures 列表——键位列只放手势短词（Click/Shift/Alt），动作列给后果；
删除与 Mouse & touch 段重复的滚轮行；六行一一对应、无重复。

**F11 · 窄窗格工具栏溢出被裁**
`src/styles.css` `.float-toolbar`。并排对比的窗格仅 ~334px，工具栏内容 ~316px + 16px
内边距放不下，最后一个按钮（◧）被窗格边缘裁掉一半。
**修复**：`flex-wrap: wrap` + `max-width: calc(100% - 18px)` 兜底；并用容器查询
（`.canvas { container-type: inline-size }`，`@container (max-width: 479px)` 隐藏
`.zoom-level`）在窄画布隐藏缩放百分比文本——工具栏恢复单行，标题芯片不再被
两行工具栏掩埋，+/− 按钮与键盘缩放不受影响。

**F12 · 图例与画布提示条叠压（~500px 窗格）**
`src/styles.css`。窄窗格下图例（≤220px）与提示条同处底部一条带，横向相撞。
**修复**：`:has(.legend) .canvas-hint { max-width: max(calc(100% - 256px), 160px) }`
——图例开启时为其预留足印（嵌套/对比分屏的图例挂在 `.split` 下、单视图挂 `.main` 下，
`:has()` 两种结构都命中；图例关闭时不损失提示条宽度）。

### P2 — 文案与一致性

**F13 · 杂项一致性**
- 侧栏控件标签省略截断（"Species branch thickn…"）：`.control-label` 允许换行
  （与分区标题的换行策略一致）；
- 转移网络页首行提示居中、第二行注脚左对齐（同屏两种对齐）：提示改用 `.rp-note`
  左对齐统一；
- **嵌套视图缺少分栏方向切换入口**：⇔ 按钮只存在于对比状态栏，嵌套视图用户无法
  发现并排模式（共享的 `rpv.split.orientation` 偏好实际支持两者）。在嵌套分屏容器
  右上（小地图上方空带）补 `⇔/⇕` 浮动按钮，复用现有 `splitSideBySide/splitStacked`
  文案键，无新增字典串。

## 二、复查后确认无需修改的疑点

- 示例数据中 E.coli_gene1 / E.coli_gene2 两个末端标签在高分辨率裁剪下确认**无重叠**
  （低倍缩略图上的粘连是缩放伪影）；标签与管道的少量交叠属布局换算的正常范围，
  且画布提供完整的标签字号/角度/偏移控制。
- 对比差异表在窄面板下末列被裁：表格容器本就横向可滚，属预期行为。
- 快捷键帮助 Esc 行 "Close panel / clear selection" 与实现一致（Esc 关面板；
  画布选区由点击空白清除，帮助卡 Mouse & touch 段已如实描述）。
