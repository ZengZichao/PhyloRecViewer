# PhyloRecViewer UI 文案风格指南

本文件是界面文字的唯一规范来源（K3）。新增或修改任何用户可见字符串时，必须同时满足本指南；`src/i18nText.test.ts` 会把其中可机械校验的规则变成 CI 失败条件。

## 1. 大小写

| 元素 | 规则 | 例 |
|---|---|---|
| 按钮、菜单项、标签页、分区标题、开关标签、表头 | sentence case（仅首词与专有名词大写） | `Reduce crossings`、`Transfer matrix`、`Load sample` |
| 句子（tooltip、说明、错误、Toast） | 首词大写、句末带标点 | `Click a label on the canvas to rename it individually.` |
| 格式名与缩写 | 按其规范拼写，不得二次大写化 | `recPhyloXML`、`phyloXML`、`Newick`、`NHX`、`PNG`、`SVG`、`PDF`、`HTML`、`CSV`、`JSON`、`DPI` |
| 程序名 | 唯一形式 `PhyloRecViewer`（`phylorecviewer` 仅用于包/二进制标识） | — |
| 插值数据（文件名、物种名、用户标签） | 原样保留大小写，禁止 CSS `text-transform` 或 JS 改写 | `Mammals.nwk` 不得显示为 `MAMMALS.NWK` |
| 强调 | 用字重/颜色，不用全大写 | 禁用 `NOT`、`FAILED` |

**禁止**在样式表中使用 `text-transform`（读屏、复制粘贴、查找、导出的文本层都会与被写下的文案不一致，且对中文无效，造成双语层级不等价）。

## 2. 标点与符号

1. 标签/按钮/菜单项/表头：无句末标点；不用冒号结尾（插值前缀除外）。
2. 句子：以句号结尾；中文用 `。`
3. 省略号：唯一形式 `…`（U+2026），只用于“点击后还需补充信息”的动作；分区标题不用。
4. 括号：英文半角 `()`，中文全角 `（）`；代码拼接优先用 ` · ` 或逗号代替括号。
5. 破折号：英文 em dash `—`；数值区间用 en dash `–`（`0–1`、`0–100`）；禁止用 ` - ` 兼任破折号。
6. 分隔符：` · `（U+00B7 + 两侧空格）唯一；禁用 `|`、`-`、`/` 作分隔。
7. 并列选项：` / `（两侧空格），中文同。
8. 引号：英文 `“ ”`，中文 `「 」`；同一句不混用。
9. 中英混排：拉丁/数字与汉字之间留 1 个半角空格。
10. 界面串中禁止：`\uXXXX` 转义、制表符、NUL、重复标点。

## 3. 称谓与句法

1. 错误文案模板：`<对象 + 失败原因>. <下一步动作>.`
2. Toast 只报事实；原理解释放“数据检查”面板或诊断信息。
3. 手势描述必须与实现一致（例如若 ⌘ 也能触发折叠，文案必须写明）。
4. 快捷键由 `modKey` 单点生成：macOS 用 `⌘⌥⌃⇧`，其他平台用 `Ctrl/Alt/Shift`；符号不得只出现在一种语言里。
5. 数字：千位分隔按界面语言；百分比 `87%` 紧排；倍率 `2×`；尺寸 `1600 × 900 px`。
6. 量词由代码注入，字典串不带量词；单复数走 `countLabel()`，禁止 `(s)`、`file(s)` 之类写法。
7. 空值统一用 `—`（英文/中文同），不得混用 `?`、`N/A`、`(none)`、`(unnamed)`。

## 4. 双语对照

1. 先写英文母句，再写中文；两份必须句类相同（陈述/疑问/祈使）、标点层级相同。
2. 占位符（`{n}`、`{name}`、`{formats}` 等）必须在两种语言中同集合；参数化一律用占位符，不得写字面量 `N`。
3. 中文不使用翻译腔名词堆叠（用“批注”而不是“信息标注”）。
4. 诊断消息由解析器保持英文规范形（供测试、QC 报告、导出文件使用），界面经 `src/i18nDiagnostics.ts` 翻译；新增解析器消息必须同时在该文件添加中文规则。

## 5. 字典与代码

1. 所有用户可见文案必须来自 `src/i18n.ts`（例外：`i18nDiagnostics.ts` 的译文表；导出物中的机器可读字段）。
2. 禁止在组件/逻辑层写中文字面量或 `locale === "zh" ? … : …` 双语三元。
3. 禁止渲染层保留英文兜底 props；本地化文案由调用方传入或组件内 `useT()` 读取。
4. 新增键必须同时在 `Dict`、`en`、`zh` 三处出现，并提供占位符一致性。
5. 删除不再渲染的键；未被引用的键会使 `i18nText.test.ts` 失败。
6. 同一概念只允许一个键；同值键应合并或让差异承担信息。

## 6. 提交前自检

- [ ] 界面截图（中/英）中无全大写小标题、无英文夹入
- [ ] 计数为 1 时读作单数（`1 gene tree`、`1 extant gene`）
- [ ] 所有 `{x}` 占位符均已替换
- [ ] 导出图图例与界面图例逐字一致
- [ ] `npm run typecheck`、`npm test`、`npm run lint` 全绿
