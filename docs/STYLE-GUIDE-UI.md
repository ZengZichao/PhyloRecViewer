# PhyloRecViewer UI 文案风格指南

本文件是界面文字的唯一规范来源。新增或修改任何用户可见字符串时，必须同时满足本指南；`src/i18nText.test.ts` 会把其中可机械校验的规则变成 CI 失败条件。

## 1. 大小写

| 元素 | 规则 | 例 |
|---|---|---|
| 按钮、菜单项、标签页、分区标题、开关标签、表头 | sentence case（仅首词与专有名词大写） | `Reduce crossings`、`Transfer matrix`、`Load sample` |
| 句子（tooltip、说明、错误、Toast） | 首词大写、句末带标点 | `Click a label on the canvas to rename it individually.` |
| 格式名与缩写 | 按其规范拼写，不得二次大写化 | `recPhyloXML`、`phyloXML`、`Newick`、`NHX`、`PNG`、`SVG`、`PDF`、`HTML`、`CSV`、`JSON`、`DPI` |
| 程序名 | 唯一形式 `PhyloRecViewer`（`phylorecviewer` 仅用于包/二进制标识） | — |
| 插值数据（文件名、物种名、用户标签） | 原样保留大小写，禁止 CSS `text-transform` 或 JS 改写 | `Mammals.nwk` 不得显示为 `MAMMALS.NWK` |
| 强调 | 用字重/颜色，不用全大写 | 禁用 `NOT`、`FAILED` |

**禁止**在样式表中使用 `text-transform`（读屏、复制粘贴、查找、导出的文本层都会与被写下的文案不一致，且对中文无效，造成双语层级不等价）。

## 2. 标点与符号

1. 标签/按钮/菜单项/表头：无句末标点；不用冒号结尾（插值前缀除外）。
2. 句子：以句号结尾；中文用 `。`
3. 省略号：唯一形式 `…`（U+2026），只用于“点击后还需补充信息”的动作；分区标题不用。
4. 括号：英文半角 `()`，中文全角 `（）`；代码拼接的字段用括号、逗号或分行组织。
5. 破折号：英文 em dash `—`；数值区间用 en dash `–`（`0–1`、`0–100`）；禁止用 ` - ` 兼任破折号。
6. 分隔符：界面文案不使用中点 `·`；并列字段用逗号、括号或分行组织，禁用 `|`、`-` 作分隔。
7. 并列选项：` / `（两侧空格），中文同。
8. 引号：英文 `“ ”`，中文 `「 」`；同一句不混用。
9. 中英混排：拉丁/数字与汉字之间留 1 个半角空格。
10. 界面串中禁止：`\uXXXX` 转义、制表符、NUL、重复标点。

## 3. 称谓与句法

1. 错误文案模板：`<对象 + 失败原因>. <下一步动作>.`
2. Toast 只报事实；原理解释放“检查”面板或诊断信息。
3. 手势描述必须与实现一致（例如若 ⌘ 也能触发折叠，文案必须写明）。
4. 快捷键由 `modKey` 单点生成：macOS 用 `⌘⌥⌃⇧`，其他平台用 `Ctrl/Alt/Shift`；符号不得只出现在一种语言里。
5. 数字：千位分隔按界面语言；百分比 `87%` 紧排；倍率 `2×`；尺寸 `1600 × 900 px`。
6. 量词由代码注入，字典串不带量词；单复数走 `countLabel()`，禁止 `(s)`、`file(s)` 之类写法。
7. 空值统一用 `—`（英文/中文同），不得混用 `?`、`N/A`、`(none)`、`(unnamed)`。

## 4. 双语对照

1. 先写英文母句，再写中文；两份必须句类相同（陈述/疑问/祈使）、标点层级相同。
2. 占位符（`{n}`、`{name}`、`{formats}` 等）必须在两种语言中同集合；参数化一律用占位符，不得写字面量 `N`。
3. 中文不使用翻译腔名词堆叠（用“批注”而不是“信息标注”）。
4. 诊断消息由解析器保持英文规范形（供测试、QC 报告、导出文件使用），界面经 `src/i18nDiagnostics.ts` 翻译；新增解析器消息必须同时在该文件添加中文规则。

## 5. 字典与代码

1. 所有用户可见文案必须来自 `src/i18n.ts`（例外：`i18nDiagnostics.ts` 的译文表；导出物中的机器可读字段）。
2. 禁止在组件/逻辑层写中文字面量或 `locale === "zh" ? … : …` 双语三元。
3. 禁止渲染层保留英文兜底 props；本地化文案由调用方传入或组件内 `useT()` 读取。
4. 新增键必须同时在 `Dict`、`en`、`zh` 三处出现，并提供占位符一致性。
5. 删除不再渲染的键；未被引用的键会使 `i18nText.test.ts` 失败。
6. 同一概念只允许一个键；同值键应合并或让差异承担信息。

## 6. 提交前自检

- [ ] 界面截图（中/英）中无全大写小标题、无英文夹入
- [ ] 计数为 1 时读作单数（`1 gene tree`、`1 extant gene`）
- [ ] 所有 `{x}` 占位符均已替换
- [ ] 导出图图例与界面图例逐字一致
- [ ] `npm run typecheck`、`npm test`、`npm run lint` 全绿

## 7. 视觉系统

界面观感与文案同属一个规范：以下规则同样按"可机械校验的进 CI、不可机械校验的进人工核对"处理。实现集中在 `src/styles.css` 的令牌区、`src/app/Icon.tsx` 与 `src/app/hooks.ts`。

### 7.1 颜色

1. 底色、表面与文字只使用中性色阶（Radix slate）；强调依靠明暗对比（`--accent` 为灰阶 12，`--accent-text` 为灰阶 1），不得引入彩色品牌色。
2. 语义色只用于状态本身：`--danger` 表示删除/错误，`--success` 表示通过，`--warning` 表示待处理；不得作为装饰底色。
3. 禁止渐变与发光。滑块的已填充段用实色元素绘制（`.slider-fill` / `.range-fill`），不复用 `linear-gradient` 技巧；定位环为静态描边（`.locate-ring`），不再脉冲。
4. 背景与表面必须在浅色、深色两套主题下都通过文字对比度检查；深色主题的阴影额外带一圈半透明白色发丝（由 `--shadow-*` 令牌统一给出）。

### 7.2 间距与圆角

1. 间距只允许 `--space-1/2/3/4/6/8/10`（4/8/12/16/24/32/40px）七档；新增布局不得写裸像素间距。
2. 圆角只允许 `--radius`（8px，表面）、`--radius-sm`（6px，控件）、`--radius-xs`（4px，标签/图标按钮）、`--radius-full`（胶囊）；禁止 3px、10px 等一次性取值。
3. 同心圆角：内层控件与所在表面同时可见时，外层半径 = 内层半径 + 内边距。工具条（外 8、内 4、内边距 4）与下拉菜单（外 8、内 4、内边距 4）是参照实现。
4. 组内紧凑、组间留白：同一组内的行距不得大于组与组之间的间距（侧栏为 4px 行距 / 16px 分组边界；设置为 4px 行距 / 24px 分组间距）。
5. 侧边栏左右内边距相等，滚动条占位用 `scrollbar-gutter: stable both-edges` 保持对称。

### 7.3 阴影

1. 浮层与卡片用多层柔和阴影区分层级（`--shadow-panel` / `--shadow-pop` / `--shadow-modal`），不用 1px 硬边框勾边；`0 0 0 0.5px` 的发丝层只作为阴影的第一层存在。
2. 容器表面（面板、对话框、菜单、图例、提示条）不得使用 `border`；`border` 只保留给表单控件（输入框、下拉框、分段控件、复选按钮）以表达可编辑性。
3. 阴影必须跟随主题变化，不允许在组件里写死 `rgba(0,0,0,…)`。

### 7.4 图标

1. 界面图标只有 `src/app/Icon.tsx` 一套：24 单位网格、统一描边宽度与端点。不得用字体符号（✓ ✕ ‹ › ▸ ▾ ⇔ ⇕ ◎ ◉ ✎ ⋯ ⋮）或 emoji 充当图标；数据标记（物种树管、事件符号、叉号表示丢失）不属于界面图标，可在图例中按图形语言绘制。
2. 图标略小于同级文字（侧栏 12–13px 对 13px 文字），图文间距统一；图标本身 `aria-hidden`，可点击控件必须有 `aria-label`。
3. 图标状态切换用交叉淡化（`IconSwap`），不做瞬间替换；带方向的图标（chevron、caret）用 transform 过渡旋转，不换字形。
4. 不使用装饰徽章：计数、警告等状态用"线性图标 + 文字"的安静按钮表达，不用彩色药丸或边框 chip 包装。

### 7.5 动效

1. 状态变化一律用 CSS transition；除加载旋转指示外禁止关键帧动画（关键帧会从头重播，无法被下一次操作打断）。
2. 入场起步快、收尾轻：统一 `--ease-out` 曲线；时长只用 `--motion-fast`（120ms）/ `--motion`（200ms）/ `--motion-slow`（280ms）。
3. 退场要"轻轻退场"：元素移出 4–12px 后淡出，并加 2–3px 模糊；不得直接删除或飞出屏幕。浮层退出由 `usePresence` 保持挂载，退出时长与 CSS 保持一致。
4. 内容或图标切换用交叉淡化 + 轻微缩放（0.98–0.995）+ 模糊；不得生硬替换。
5. 错开入场：同一批出现的内容按 30ms 步进延迟（`.stagger-children`），最后一项应在首帧后约 240ms 内到位。
6. `prefers-reduced-motion: reduce` 下所有入场/退场过渡关闭，但状态本身（显示/隐藏、位置）仍必须正确。

### 7.6 布局

1. 同一列元素严格左对齐：侧栏标题、分组标题与每一行控件名称共用同一条 16px 基线；设置页名称列与分组标题共用一条基线。
2. 数字列（计数、百分比、缩放、坐标、置信度）使用 `font-variant-numeric: tabular-nums`，数值变化不得引起左右跳动。
3. 标题使用 `text-wrap: balance`，避免末行只剩一个词；应用内保留一个可被读屏读取的 `h1`。
4. 侧边栏与相邻面板同圆角、同阴影、不贴窗口边缘；不同窗口宽度下（1440/1280/1024）都必须保持面板间距与内部对齐。
5. 浮层（图例、统计、迷你图、工具栏、节点检视卡）之间不得互相遮挡；窄画布下允许收起次要读数，但不得把两个浮层叠在一起。

### 7.7 设置页与控件选择

1. 设置项一项一行、名称左、控件右；分组标题在上，组间留白大于组内；删除/重置类操作单独置于页面底部。
2. 小控件、独立保存的设置用左右排；按顺序填写的表单（批注、重命名）用上下排，名称在上、输入区全宽。
3. 控件语义：复选框只用于"选好再提交"的表单；开关点击即生效；少量互斥选项用分段控件；下拉框用于展开浏览，组合框用于输入检索；工具栏状态用切换按钮；筛选条件用可叠加的筛选标签；滑块用于凭手感调整，精确小范围值用可编辑数值/步进器。
4. 每个可点击控件的命中区不小于 28×28px（触控设备 44×44px）。
