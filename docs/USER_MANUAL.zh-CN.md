## 1. 软件概述

PhyloRecViewer 是面向演化生物学研究者的**基因－物种调和（gene–species reconciliation）可视化查看器**。它原生支持 **recPhyloXML** 格式，并直接读取带 `[&&NHX]` 注释的调和基因树，无需任何前置转换脚本。软件完全离线运行，可交互式浏览大规模调和事件（物种形成、基因重复、基因丢失、水平基因转移等），并提供搜索过滤、统计、转移网络、一致性检查与出版级导出能力。

### 1.1 核心特性

- 离线桌面应用，数据不离开本机
- recPhyloXML 与 NHX / Newick 双格式自动识别
- 三层嵌套调和视图（基因 → 共生体 → 宿主）
- 两个调和结果的并排对比视图（自动高亮不一致节点）
- 丰富的布局与样式参数实时调节（四方向、紧凑布局、分支长度等）
- 节点搜索（支持正则）、事件类型过滤、基因家族过滤、置信度区间过滤
- 统计报表（含 CSV 导出）、转移网络环形图、十一项数据一致性检查
- 批量重命名标签、节点标注（含标注管理模式）
- 撤销 / 重做（100 步）、会话保存恢复、多标签页
- 一键导出 PNG（600–4800 DPI 可选）/ SVG / PDF / 交互式 HTML / NHX
- 中英双语界面，浅色 / 深色 / 跟随系统三档主题
- 四套内置示例：综合示例、全事件类型示例、基因 / 共生体 / 宿主嵌套视图、并排对比（见[第 4.5 节](#45-加载示例数据)）

### 1.2 快速入门

1. **启动软件**：启动后显示空状态起始页——可**打开文件**、**载入示例**（四个内置示例之一）、把文件拖进窗口，或点**快捷键与帮助**先熟悉操作。
2. **打开自己的数据**：菜单 **文件 → 打开文件**（或按 `⌘O` / `Ctrl+O`），选择 `.recphyloxml`、`.xml` 或 `.nhx` 文件；也可以直接把文件拖进窗口。
3. **浏览**：滚轮缩放、拖拽空白处平移、按 `F` 适应视图。
4. **交互**：单击基因节点高亮其谱系；`Shift` + 单击添加标注；`Alt`/`⌥` + 单击内部节点折叠子树；单击物种枝镜像（换枝）。
5. **分析**：点击画布左上角 **◧** 按钮打开右侧分析面板，使用搜索过滤、结果统计、转移网络与数据检查（详见[第 7 节](#7-右侧分析面板)）。
6. **导出**：菜单 **导出** 选择 PNG / SVG / PDF / HTML 出版级图像，或 **NHX · Newick** 数据导出。

> 界面右下角的"提示"清单和 **帮助** 菜单中的快捷键速查可随时唤起（按 `?`）。

### 1.3 术语表

| 术语 | 说明 |
|------|------|
| **调和（reconciliation）** | 基因树与物种树之间的映射，用于推断物种形成、重复、丢失、转移等事件 |
| **recPhyloXML** | 本软件的原生文件格式，以 `<recPhylo>` 为根元素 |
| **NHX** | 一种带注释的基因树格式（`[&&NHX]`），可承载调和事件信息 |
| **镜像 / 换枝（swap）** | 左右翻转某个物种子树，用于减少转移交叉；软件内部称 `swap` |
| **谱系（lineage）** | 某个基因节点从其祖先到后代的完整路径 |
| **物种管道（species tube）** | 画布上表示物种树分枝的粗线段 |
| **转移弧（transfer arc）** | 连接供体与受体的虚线箭头，表示水平基因转移 |
| **事件（event）** | 基因节点的演化事件类型，共七类（见[第 8 节](#8-图例)） |

## 2. 安装与启动

### 2.1 桌面版（推荐）

1. 从发布页（GitHub Releases）下载对应系统的安装包。
2. 安装并启动 **PhyloRecViewer**。
3. 启动后显示空状态起始页：可打开文件、载入内置示例、拖入文件或查看快捷键帮助。

| 平台 | 安装包 |
|---|---|
| macOS（Apple Silicon / Intel） | `.dmg` |
| Windows | `.exe` 安装器（或 `.msi`） |
| Linux | `.deb`（或 `.AppImage`） |

桌面窗口默认尺寸 1320×860，最小 900×600。

### 2.2 浏览器版

构建产物位于 `dist/`，请用 `npm run preview` 起本地服务后打开其打印出的 `http://localhost:4173/` 地址：产物以 ES 模块方式加载脚本，浏览器不允许在 `file://` 页面下执行模块脚本，因此直接双击打开 `dist/index.html` 只会看到空白窗口。浏览器版使用浏览器自带文件选择器与下载功能，**不支持**系统原生文件对话框与文件关联打开。其余功能（画布、分析、导出下载）与桌面版一致。

### 2.3 从源码运行（开发者）

```bash
cd PhyloRecViewer
npm install
npm run dev        # 浏览器开发服务器（Vite，http://localhost:5173）
npm run tauri dev  # 桌面（Tauri）开发模式
npm run build      # 生产构建 -> dist/
npm test           # 运行 Vitest 单元测试
npm run typecheck  # tsc -b 类型检查
npm run lint       # ESLint
```

前置条件：Node.js 20+、npm 9+；桌面打包还需 Rust 1.77+。

## 3. 界面总览

界面自顶向下、由左到右分为以下区域：

```
┌──────────────────── 菜单栏（MenuBar）：文件 | 导出 | 视图 | 帮助 ─────────────────┐
│            （右侧：警告徽章 ··· 文件名信息 · 弹性空白，可拖动移动窗口）             │
├────────────────────── 标签栏（TabBar）：多文档标签 ＋ 新建 ───────────────────────┤
├─ 左侧面板 ──┐ ┌──────────────────── 主画布（Canvas） ──────────────┐ ┌─ 右侧面板 ─┤
│ 控制面板     │ │  左上：浮动工具栏（缩放/适配/撤销/标注/分析）        │ │ 分析面板    │
│  布局操作   │ │  中部：物种管道 + 基因骨架 + 转移弧 + 标签 + 标注   │ │  搜索过滤   │
│  布局参数   │ │  左下：图例 + 小地图                                │ │  结果统计   │
│  样式       │ │                                                     │ │  转移网络   │
│  标签       │ │                                                     │ │  数据检查   │
│ （提示）    │ │                                                     │ │  信息标注   │
│             │ │                                                     │ │ （差异）    │
└─────────────┘ └─────────────────────────────────────────────────────┘ └────────────┘
```

- **菜单栏（MenuBar）**：文件、导出、视图、帮助四个下拉菜单（详见[第 12 节](#12-菜单栏参考)）。解析有警告时菜单栏会显示警告数徽章，悬停可查看全部警告。
- **标签栏（TabBar）**：多文档标签，支持新建、切换、关闭（详见 4.8）。
- **左侧面板（控制面板）**：布局操作、布局参数、样式、标签四个可折叠区块，底部有操作提示（详见[第 6 节](#6-左侧控制面板)）。
- **主画布（Canvas）**：核心可视化区域。左上角为浮动工具栏（缩放、适配视图、撤销/重做、标注模式、分析面板开关），左下角为图例与小地图（详见[第 5 节](#5-画布浏览与交互)）。
- **右侧面板（分析面板）**：搜索过滤、结果统计、转移网络、数据检查、信息标注五个固定标签页；对比模式下额外出现"差异"标签页（详见[第 7 节](#7-右侧分析面板)）。

> 左右侧面板均可通过拖动分隔条调整宽度；点击面板顶部的 `‹` / `›` 按钮可收起 / 重新展开。窗口宽度低于 1000 px 时分析面板自动收起，低于 820 px 时左侧面板也会自动收起（均可手动重新打开）。

## 4. 文件操作

### 4.1 打开文件

菜单 **文件 → 打开文件**（快捷键 `⌘O` / `Ctrl+O`）：

- **桌面版**：弹出系统原生文件选择器，可一次多选。
- **浏览器版**：弹出浏览器文件选择器。

支持的扩展名：`.recphyloxml` `.recphylo` `.xml` `.phyloxml` `.nhx` `.nwk` `.newick`（自动识别格式，无需手动指定，详见[第 15 节](#15-支持的文件格式)）。

打开单个文件时自动解析并渲染。若当前标签页是空白或只显示内置示例，则在当前标签打开；否则新建标签页以保留已有工作。

### 4.2 多文件打开：合并还是分标签

一次选择 / 拖入 **多个文件** 时，会弹出 **"如何打开 N 个文件？"** 对话框：

- **合并为一个文档**：以第一个文件的物种树为基准，把所有文件的基因家族合并进同一次调和；各家族按来源文件命名并用不同颜色区分。若后续文件引用了第一个物种树中不存在的物种，会计入警告。
- **每个文件新建标签**：每个文件独立成标签页，互不影响。

合并成功后显示"已将 N 个文件合并为 1 个调和文档"提示。

### 4.3 拖放打开

把一个或多个文件 **拖拽到窗口任意位置**，出现 **"释放以打开"** 覆盖提示，松手即可打开。拖放多文件时同样会询问合并还是分标签（见 4.2）；拖放单个文件到已有内容的窗口时**始终新建标签页**。

### 4.4 系统关联打开（双击 / "打开方式"）

桌面版注册了文件关联：`.recphyloxml` / `.recphylo` 与 `.xml` / `.phyloxml`（recPhyloXML），以及 `.nhx` / `.nwk` / `.newick`（NHX / Newick）。由于 `.xml` 是通用扩展名，注册后本软件可能成为其它 XML 文档的候选默认程序；如不需要，可在系统设置中取消 `.xml` 的关联。在系统文件管理器中：

- **双击**此类文件，或 **右键 → 打开方式 → PhyloRecViewer**，会用该文件启动 / 唤醒应用。
- 应用已在运行时，新文件会作为新标签页载入（macOS 通过 `open-file` 事件）。

### 4.5 加载示例数据

菜单 **文件 → 载入示例…** 内置 4 套示例（菜单标签描述示例所含的事件，并随界面语言显示）：

| 示例 | 说明 |
|------|------|
| **完整示例**（Showcase） | 综合示例：物种形成 / 重复 / 丢失 / 转移 |
| **全事件类型**（All event types） | 一棵树中涵盖全部调和事件类型，含基因转移（供体）与树外分叉 |
| **对比示例** | 同一家族的两种推断结果（自动进入对比视图） |
| **嵌套示例** | 基因 / 共生体 / 宿主三层（自动进入嵌套视图） |

加载示例后标签页会标记为示例状态；打开真实文件时该标记自动清除。空状态页与解析失败面板上也有 **"载入示例"** 快捷入口。

### 4.6 嵌套层（三层视图）

菜单 **文件 → + 嵌套层** 加载第二个调和文件作为**宿主（Host）层**，进入三层视图：

- 左侧画布：**基因 → 共生体**（Gene → Symbiont）
- 右侧画布：**共生体 → 宿主**（Symbiont → Host）

加载后菜单项变为 **"嵌套：<文件名> ✕"**，点击即移除嵌套层，回到单层视图。嵌套画布的物种镜像（换枝）状态独立于主画布保存（内部为 `nestedSwapped` 与 `swapped` 两套集合），同名物种不会互相影响。

> 注意：更换主文件会自动清除已加载的嵌套层与对比。嵌套文件解析出错时，画布顶部会显示黄色横幅（"嵌套文件错误：…"）。

### 4.7 对比视图

菜单 **文件 → + 对比** 加载另一份调和结果（通常用于同一基因家族的不同工具 / 参数的推断），进入对比视图：

- 两个画布并排，标题分别为文件名（A / B）。
- 软件**自动高亮两个结果不一致的基因节点**（基于节点的事件类型与物种映射差异），图例中出现"两个文件不一致的节点"色块，可在差异标签页中**隐藏高亮**。
- 顶部徽章显示一致率与已比较基因节点数，例如 `71% 一致 · 7 基因节点`。
- 对比模式下右侧面板自动出现 **差异** 标签页（见 7.6）。

加载后菜单项变为 **"对比：<文件名> ✕"**，点击移除对比。

> 注意：嵌套层与对比**互斥**，加载其一会自动清除另一个。

### 4.8 多标签页

- 菜单栏下方标签栏右侧 **＋** 按钮：新建空白标签页。
- 点击标签切换文档；每个标签页独立保存各自的文件、镜像、折叠、家族颜色、标注、重命名、搜索条件与撤销历史。
- 悬停标签显示 **✕** 关闭按钮。若文档包含未导出的标注、换枝或颜色修改，关闭时会弹出确认框（"关闭标签页？…… 保留 / 仍关闭"），防止误丢工作；关闭最后一个标签会重置为空白标签而非退出。
- 关闭当前激活标签时，自动激活相邻标签。
- 标签栏支持键盘操作：`←` / `→` 切换，`Home` / `End` 跳至首尾，`Enter` / `空格` 激活。

## 5. 画布浏览与交互

### 5.1 画布浮动工具栏

画布**左上角**有一组浮动按钮（仅主画布显示撤销 / 重做与分析开关）：

| 按钮 | 功能 |
|------|------|
| `−` | 缩小（1/1.2） |
| `100%` | 当前缩放比例（实时显示） |
| `＋` | 放大（1.2×） |
| `⤢` | 适应视图（同 `F`） |
| `↶` / `↷` | 撤销 / 重做（同 `⌘Z` / `⌘⇧Z`） |
| `✎` | **标注模式**开关（见 5.8） |
| `◧` | 打开 / 关闭右侧分析面板 |

### 5.2 缩放与平移

| 操作 | 说明 |
|------|------|
| **滚轮** | 以鼠标位置为中心缩放 |
| **拖拽空白处** | 平移画布 |
| **`⌘ +` / `⌘ =`（mac）或 `Ctrl +` / `Ctrl =`** | 放大 1.2× |
| **`⌘ -` / `Ctrl -`** | 缩小 1/1.2 |
| **`F`** 或 `⤢` 按钮 | 适应视图 |
| **缩放比例显示** | 浮动工具栏内实时百分比 |

缩放范围 **3% – 1000%**。缩放级别驱动细节层次（LOD）：极度缩小时自动隐藏标签与事件符号，保证可读性与渲染性能。数据量大时画布左下角会短暂显示"渲染中…"指示。

### 5.3 适应视图

按 **F** 或点击 `⤢` 按钮，画布自动缩放并居中完整图谱。载入新文件、切换标签或改变树朝向时会自动适应；图面因参数变化显著增大时（如调大层高）也会自动重新适应，避免内容溢出视口。

### 5.4 小地图

左侧面板 **布局参数 → 小地图** 开关可开启 / 关闭小地图（画布左下角，168×120）：

- 缩略显示物种骨架与当前视口（高亮矩形）。
- 在小地图内 **拖拽** 可平移主画布视口；滚轮事件被小地图独占，不会触发主画布缩放。

### 5.5 基因节点交互

| 操作 | 效果 |
|------|------|
| **悬停** | 工具提示：基因名 / 事件类型 @ 物种 |
| **单击** | 高亮该节点的**谱系**（祖先 → 后代整条路径），其余节点变暗；再次单击空白处取消 |
| **`Shift` + 单击** | 打开**标注编辑器**（见 5.8） |
| **`Alt` / `⌥` + 单击内部节点** | 折叠 / 展开该子树（见 5.7） |
| **单击空白处** | 清除谱系高亮，回到搜索 / 过滤的变暗状态 |

高亮优先级：手动点击的谱系 > 搜索 / 过滤变暗。首次悬停基因节点时会出现一次性的操作提示气泡（"节点操作"），点击"明白了"关闭。

### 5.6 物种枝交互（镜像 / 换枝）

- **单击物种枝**（有子节点的物种）：**镜像该子树**（toggle swap），再次单击恢复。
- 用途：**减少转移交叉**——把容易产生交叉的子树翻到另一侧。也可以用左侧面板的**减少交叉**按钮自动优化。
- 镜像状态计入撤销 / 重做历史。
- 三层视图中，左右画布的镜像状态**独立**保存，同名物种不会串扰。

### 5.7 折叠 / 展开

- **`Alt` / `⌥` + 单击内部基因节点**：折叠 / 展开该子树。
- 折叠后的子树显示为**楔形（wedge）**，指向叶方向并标注叶数，如 `已折叠 (12) 叶`。
- 再次 `Alt` / `⌥` + 单击展开；折叠状态计入撤销 / 重做历史；悬停楔形会提示"Alt 点击展开"。

### 5.8 标注

两种方式添加 / 编辑标注：

- **`Shift` + 单击**基因节点，直接弹出标注编辑器；
- 或点击浮动工具栏 **✎ 进入标注模式**（按钮高亮），此后**单击**任意基因节点即可标注；再次点击 `✎` 退出标注模式。

标注编辑器：输入文字、选择颜色后点**保存**（或 `⌘Enter`），节点显示**彩色圆环 + 文字**；可**删除**或**取消**（`Esc`）。已保存的标注集中在右侧面板 **信息标注** 标签页中统一管理（见 7.5）。标注保存在会话文件中（见[第 10 节](#10-会话保存与加载)）。

### 5.9 画布上重命名标签

**单击**画布上的任一名称标签（物种名，或带名称的基因标签；光标会变为手型），出现内联输入框：`Enter` 确认、`Esc` 取消、失焦提交。重命名属于可撤销操作，也可在左侧面板 **标签** 区块中批量执行或重置（见 6.4）。

## 6. 左侧控制面板

左侧面板标题为**控制面板**，含四个可折叠区块（折叠状态记忆在本地，可点击区块标题右侧图钉固定展开）；底部有**提示**清单，汇总画布操作要点。

### 6.1 布局操作

| 按钮 | 说明 |
|------|------|
| **减少交叉** | 以启发式缩短转移弧：自动镜像子树（同时优化主画布与嵌套画布）。目标函数是供体—受体的叶序距离之和，它是交叉数的代理而非交叉计数；最多迭代 8 轮、每轮最多考察 256 个候选子树，因此超大且富含转移的物种树只能被部分优化 |
| **重置换枝** | 清除所有镜像 |
| **全部重置** | 将所有布局与样式参数恢复为默认值 |

### 6.2 布局参数

| 参数 | 范围 | 说明 |
|------|------|------|
| **图例** | 开/关 | 在画布上显示图例，并在导出图像时一并包含 |
| **小地图** | 开/关 | 显示 / 隐藏左下角小地图 |
| **树朝向** | 根在上 / 下 / 左 / 右 | 四向单选按钮 |
| **层高** | 40–220 | 相邻物种层之间的距离 |
| **基因间距** | 8–42 | 相邻基因树之间的水平间距 |
| **物种间距** | 8–70 | 相邻物种叶节点之间的间距 |
| **物种树粗细** | 12–80 | 物种管道的粗细 |
| **基因树粗细** | 1–5（步长 0.2） | 基因骨架线的粗细 |
| **末端对齐** | 开/关 | 所有基因叶节点对齐到同一基准线 |
| **分支长度** | 开/关 | 按分支长度布局（而非等长） |
| **紧凑布局** | 开/关 | 相邻子树尽量靠拢（轮廓法），而非固定宽度叶槽 |
| **重复事件居中** | 开/关 | 基因重复节点放在物种分支**中点**（否则更靠近祖先端） |

### 6.3 样式

| 参数 | 范围 | 说明 |
|------|------|------|
| **曲线分支** | 开/关 | 物种枝为圆角曲线还是直角折线 |
| **符号大小** | 4–16 | 事件符号大小 |
| **转移弧度** | 0–0.5（步长 0.02） | 转移弧的弯曲程度 |
| **基因描边** | 开/关 | 基因线加浅色描边（halo），提升在物种管道上的对比度 |
| **事件符号** | 开/关 | 是否显示事件符号（重复方块、丢失叉号等） |
| **支持值** | 开/关 | 是否显示支持度 / 置信度数值 |
| **管道渐变** | 开/关 | 物种管道使用渐变色填充 |
| **重叠拷贝数（泳道）热力图** | 开/关 | 物种管道按其内部排布的基因 lane 数（布局引擎的并发泳道数）热力着色。这是布局量而非基因拷贝数：不含丢失的每物种基因计数在统计面板中单列为 **谱系（非丢失）** |

### 6.4 标签与批量重命名

三类标签分别开关与设样式：

- **物种名**
- **基因末端节点名称**
- **基因内部节点名称**

每类标签可独立调节：**角度**（−90°–90°，步长 5°）、**字号**（6–28）、**加粗**、**斜体**、**偏移**（−40–140）、**对齐**（自动 / 左对齐 / 居中对齐 / 右对齐）。

区块底部还有：

- **批量重命名**：打开对话框，支持**正则表达式**；**查找** / **替换为** 输入框；**范围**可选物种名称 / 基因名称 / 全部标签；点**应用**生效。
- **重置标签**：存在重命名记录时显示，一键恢复原始名称。
- 画布上**单击**单个标签可就地重命名（见 5.9）。

## 7. 右侧分析面板

点击浮动工具栏 **◧**（或 `Esc` 关闭后用 `⌘F` 直接跳到搜索标签页）打开 / 关闭右侧分析面板。面板含五个固定标签页，对比模式下额外出现第六个：

**搜索过滤 / 结果统计 / 转移网络 / 数据检查 / 信息标注 /（差异）**

> 键盘操作：标签栏可用 `←` / `→`、`Home` / `End` 切换。

### 7.1 搜索过滤

- **搜索框**：输入基因名或物种名；勾选**正则表达式**启用正则搜索。
- 按 `Enter` 跳至下一个匹配，`Shift + Enter` 跳至上一个；也可以用 **下一个 / 上一个** 按钮，每次跳转将主画布**居中**到该节点。匹配计数显示如 `12 个匹配`，无匹配时显示"无匹配"。
- **按事件类型**：勾选物种形成 / 基因重复 / 基因丢失 / 基因转移四类，仅显示勾选类型相关的节点。
- **按基因家族**：多基因树时，每个家族前带颜色色块，勾选切换显示。
- **置信度区间**：两个滑块设定支持值范围（0–1），过滤低置信节点。
- **仅显示匹配**：开启后只渲染匹配节点（默认将不匹配节点变暗至透明度 0.12）。
- **清除筛**：一键清空搜索词、正则开关、事件过滤、家族过滤与置信度区间。

### 7.2 结果统计

- **总计**：物种形成 / 基因重复 / 基因丢失 / 基因转移四类事件计数，以及末端节点数、内部节点数、节点总数。转移（到达）为叠加事件，不计入构成占比，其计数见总计。
- **事件分布**：各事件类型的占比视图。
- **按家族**（多基因家族时）：每个家族的事件计数表。
- **转移矩阵**：供体 → 受体的转移次数表（前 25 条），列为供体 / 受体 / 次数。
- **按物种（前列）**：每个物种的 **谱系（非丢失）**（所载基因谱系数，不含丢失）、物种形成、重复、丢失、转移（供体）、树外分叉与现存基因计数（前 25 个物种）。
- **节点**：全部节点明细表（编号、名称、类型、事件、物种、所属家族），数据量大时表格截断并提示"表格已截断"。
- **导出 CSV**：将统计结果导出为 `<文件名>-stats.csv`。

### 7.3 转移网络

以**环形图**展示供体 → 受体的转移关系：

- 节点 = 物种，大小按涉及的转移数加权；箭头 = 转移方向，粗细表示次数。
- **悬停**节点可聚焦其相关转移，其余变暗。
- 自转移（供体 = 受体）显示为小圆环。
- 无转移事件时显示"无转移事件"。
- 底部提示：节点=物种，箭头=转移（越粗越多），悬停可聚焦。

### 7.4 数据检查

对载入数据做十一项结构检查，每项显示**名称**、问题描述与计数：

| 检查项（名称） | 发现的问题 |
|----------------|-----------|
| 物种引用有效 | 基因引用了物种树中不存在的物种 |
| 物种命名唯一 | 物种树中存在重名物种 |
| 基因均有物种归属 | 基因节点未分配物种 |
| 现存基因落在叶物种 | 现存基因位于内部（非叶）物种 |
| 转移供体配对完整 | 转移供体缺少转移（到达）子节点 |
| 转移受体有供体谱系 | 转移（到达）缺少供体谱系 |
| 转移受体位于供体之下 | 转移（到达）的父节点不是分叉/双分叉供体 |
| 双分叉供体配对完整 | 双分叉（bifurcation-out）供体缺少转移（到达）子节点 |
| 丢失/现存事件为叶 | `loss`/`leaf`（终端）节点带有子节点 |
| 物种形成/复制为二叉 | 物种形成或复制节点不是二叉 |
| 转移在时间上前向 | 转移到达进入某物种的祖先（时间倒流） |

全部通过时显示**"全部通过"**；有问题时顶部提示"N 项有问题"。

### 7.5 信息标注

集中管理当前文档的全部标注：列出每个标注的节点与内容，可跳转、编辑或删除；无标注时提示"还没有标注。Shift 点击基因节点（或使用标注模式）添加一条。"

### 7.6 差异（对比模式）

仅在对比视图（4.7）下出现：

- 列出 / 高亮**两个文件不一致的节点**（事件类型或物种映射不同）。
- **隐藏高亮**开关可临时关闭差异高亮，便于查看原图。
- 配合顶部 `71% 一致 · N 基因节点` 徽章阅读。

## 9. 导出

菜单 **导出**（无内容时置灰；快捷键 `⌘E` / `Ctrl+E` 直接导出 PNG）：

### 9.1 图像 / 页面

| 格式 | 说明 |
|------|------|
| **PNG** | 位图；分辨率在菜单内选择：**600 / 1200 / 2400 / 4800 DPI**，适合幻灯片与文档。当图形过大时，按两条平台画布上限中**更严格**的一条自动降级——最长边 16,384 px，且总像素不超过 16,384²/4 ≈ 6.7×10⁷；对接近正方形的图幅，总面积限制会先生效（约单边 8,192 px）。系统会以提示告知实际使用的 DPI |

| **PDF** | 矢量页面，适合论文插图 |
| **HTML** | 交互式 HTML（保留缩放 / 平移 / 悬停提示），可离线分享 |

- 导出中菜单显示"导出 …"，完成后弹出"已导出"提示，失败时提示"导出失败"及原因。

### 9.2 数据

- **NHX · Newick**：把当前调和结果导出为带事件注释的 NHX 基因树，文件名 `<文件名>.nhx`。

> 桌面版通过系统保存对话框选择路径；浏览器版直接下载到默认下载目录。

## 10. 会话保存与加载

菜单 **文件 → 保存**（`⌘S` / `Ctrl+S`）：保存当前会话为 `.rpvsession.json`；**文件 → 载入**：从 `.rpvsession.json` 恢复。

会话为纯 JSON（schema 版本标记由 `src/session.ts` 中的 `CURRENT_SESSION_VERSION` 定义），包含：

- 源文件内容（`xml`）及嵌套层 / 对比的源文件与文件名
- 合并文档的**完整来源文件列表**（`sourceFiles`），重新载入时可原样重建合并结果
- 全部布局参数、渲染参数、主题
- 物种镜像集合（主画布与嵌套画布分开）、折叠集合
- 每个基因树的颜色、每个节点的标注、标签重命名记录
- 当前的**搜索与过滤条件**（`searchQuery`、`searchRegex`、`eventFilter`、`familyFilter`、`confidenceMin` / `confidenceMax`）
- **其余所有打开标签页的快照**（`tabs`）与其中处于激活状态的标签（`activeTabIndex`），保存并重新载入即可恢复整个工作区，而不只是当前文档

**兼容性**：字段缺失的会话文件按默认值打开；schema 版本标记高于本构建的会话文件会被拒绝，并提示"此会话由更新版本的 PhyloRecViewer 创建（vN），请升级后打开"。缺少 `xml` 字段的 JSON 会被拒绝，提示 "Not a PhyloRecViewer session file"。

> 会话保存的是源文件内容与视图状态，**不**包含导出图像，因此文件小、适合长期归档与协作共享。

## 11. 撤销 / 重做

- **撤销**：`⌘Z` / `Ctrl+Z`，或画布浮动工具栏 `↶`
- **重做**：`⌘⇧Z` / `Ctrl+Shift+Z` 或 `Ctrl+Y`，或 `↷`

可撤销的操作：物种镜像（换枝）、折叠 / 展开、基因家族颜色修改、标注添加 / 修改 / 删除、标签重命名（单个与批量）、减少交叉、重置换枝。历史记录上限 **100 步**；连续拖动同一滑块会合并为一步，避免刷爆历史。

> 快捷键在文字输入框（INPUT / TEXTAREA / 可编辑区域）内不触发，避免与文本编辑冲突。

- **快捷键与帮助浮层**（`?` 或 菜单 帮助 → 快捷键与帮助）：列出全部键盘快捷键、图上操作手势与鼠标 / 触控提示，底部可一键重放新手指南。`Esc`、点击背景或 ✕ 关闭。
- **新手引导**：共 **5 步**（控制面板 → 分析面板 → 画布交互 → 嵌套与对比 → 导出），带聚光高亮；`←` / `→` 翻页，可跳过。可从 **帮助菜单 / 设置对话框 / 帮助浮层** 随时播放。
- **节点操作气泡**：首次悬停基因节点时出现一次性提示（"点击高亮谱系；Shift 标注；Alt 折叠"）。
- **空状态**：空白标签页提供"打开 recPhyloXML 文件"说明、**载入示例 ▸** 快捷入口与拖放提示。
- **解析失败面板**：显示"无法解析该文件"与支持格式说明，并提供 **重新选择文件 / 返回上一份 / 载入示例** 三个恢复操作。

## 15. 支持的文件格式

软件自动检测格式，无需手动指定：

| 格式 | 扩展名 | 说明 |
|------|--------|------|
| **recPhyloXML** | `.recphyloxml` `.recphylo` `.xml` `.phyloxml` | 原生格式，根元素 `<recPhylo>` |
| **NHX** | `.nhx` `.nwk` `.newick` | 调和基因树（含 `[&&NHX]` 注释） |
| **Newick** | `.nwk` `.newick` | 系统发育树（经 NHX 解析器） |
| **PhyloXML** | `.phyloxml` | 系统发育树 |

**检测逻辑**：先检查文件前 8000 字符是否包含 `<recPhylo` 或 `[&&NHX]` / 以 `(` 开头；否则按扩展名判断；默认回退到 recPhyloXML。

**NHX 标签方言**：解析器识别 `S=`（节点所属物种；`SP=` 作为别名同样接受）、`D=`（重复）、`L=`（丢失）、`BO=` / `BC=`（转移供体）、`TB=`（转移到达）与 `BL=`（基因树枝长）。不带任何事件标签的节点按结构回退为末端 / 物种形成；同一节点上多个事件标签冲突时，采用与 recPhyloXML 相同的优先级（重复 > 丢失 > 出枝转移 > 树外分叉），并给出点名该冲突的警告。其余标签键仍留在文件中，但不参与建模，软件会以警告列出被丢弃的键名，不做静默丢失。

**多文件合并**：见 4.2——以第一个文件的物种树为基准合并基因家族，缺失物种计入警告。

**桌面版文件关联**：安装后双击 `.recphyloxml` / `.recphylo`、`.xml` / `.phyloxml` 或 `.nhx` / `.nwk` / `.newick` 即用本软件打开（见 4.4）。

## 17. 常见问题与排错

### Q1 打开文件报错"无法解析该文件"

- 确认文件是 **recPhyloXML**（根元素 `<recPhylo>`）或 **NHX** 格式的调和结果。
- 普通 Newick / PhyloXML 系统发育树（无调和事件注释）无法直接可视化——需先由 Ancestors、ALE、Cogent 等工具生成调和结果。
- 检查文件编码是否为 UTF-8、文件是否完整未截断。
- 失败面板上可直接**返回上一份**文档或**载入示例**继续工作。

### Q2 嵌套层或对比加载失败

- 嵌套与对比**互斥**：加载其一会自动清除另一个，属正常行为。
- 更换主文件会自动清除嵌套层与对比。
- 嵌套 / 对比文件独立解析，错误以黄色横幅显示在画布顶部（如"嵌套文件错误：…"）。

### Q3 转移交叉较多、图面杂乱

- 左侧面板 **减少交叉** 自动优化镜像（同时优化嵌套画布）。
- 手动 **单击物种枝** 逐枝镜像。
- 开启 **紧凑布局** 使子树靠拢。
- 调大 **转移弧度**，便于辨识转移弧的起止。

### Q4 导出图像模糊 / 分辨率不够

- 论文插图优先用矢量格式 **SVG / PDF**。
- **PNG** 在 **导出菜单 → PNG DPI** 或 **设置** 中选择 1200 / 2400 / 4800 DPI 高分辨率档位。

### Q5 会话文件打不开

- 确认是 `.rpvsession.json` 且为合法 JSON。
- 若由更新版本生成，旧版本会提示"请升级后打开"，请更新软件。
- 缺少 `xml` 字段的 JSON 会被拒绝（"Not a PhyloRecViewer session file"）。

### Q6 如何批量导入多个基因家族

- 文件选择器中**多选**多个文件（或拖放多个文件），在弹窗中选择**合并为一个文档**。
- 软件以第一个文件的物种树为基准合并；若选择**每个文件新建标签**则互不合并。

### Q7 浏览器版与桌面版差异

| 功能 | 桌面版 | 浏览器版 |
|------|--------|----------|
| 文件对话框 | 系统原生 | 浏览器默认 |
| 文件关联打开 | 支持 | 不支持 |
| 保存路径 | 可选路径 | 下载到默认目录 |
| 离线能力 | 完全离线 | 首次加载后离线 |

### Q8 误关了带标注的标签页怎么办

关闭含未导出标注 / 换枝 / 颜色修改的标签时会弹出确认框（"保留 / 仍关闭"）；若已保存过会话，可通过 **文件 → 载入** 恢复。此外，工作区自动保存会对**所有打开的标签页**（而非仅当前标签）定期快照，应用意外退出后重新启动时，每个标签页的文档与视图状态都会一并恢复。

## 18. 附录

### A. 软件架构（供开发者参考）

- 前端：React 18 + TypeScript（严格模式）+ Vite + Zustand（状态管理）+ d3-zoom / d3-selection + SVG 渲染
- 桌面壳：Tauri 2（Rust）——原生文件对话框、文件关联、`open-file` 事件
- 解析器：`fast-xml-parser`（recPhyloXML）+ 自研 NHX / Newick 解析
- 布局：六步布局流水线（物种布点 → 基因嵌入 → 转移弧 → 优化）
- 导出：`jspdf` + `svg2pdf.js`（PDF）、原生 SVG / PNG 序列化、自研交互式 HTML 导出
- 测试：Vitest（覆盖解析、布局、统计、校验、会话等模块）

### B. 事件类型一览

| 内部类型 | 中文名 | 英文名 | 符号 |
|----------|--------|--------|------|

| branchingOut | 基因转移（供体） | Transfer (donor) | 空心圆环 |

`version`（会话 schema 版本标记）、`fileName`、`xml`、`sourceFiles`（合并文档的完整文件列表）、`nestedName` / `nestedXml`、`compareName` / `compareXml`、`layoutOptions`、`renderOptions`、`themeId`、`swapped`、`nestedSwapped`、`collapsed`、`geneColors`、`annotations`、`labelOverrides`、`tabs`（其余每个已打开标签页的快照）、`activeTabIndex`，以及检索与筛选条件 `searchQuery`、`searchRegex`、`eventFilter`、`familyFilter`、`confidenceMin`、`confidenceMax`。

### D. 实际上限

以下为代码中的硬性限制，不是配置建议；触及时会给出可读错误而非静默截断。

| 限制项 | 数值 | 作用位置 | 超限行为 |
|---|---:|---|---|
| 打开文件大小上限 | 64 MiB | 原生打开对话框与系统关联打开 | 拒绝读取并提示上限 |
| clade 嵌套深度 | 1,000 | recPhyloXML、NHX 与 Newick 读取器 | 以"嵌套过深"错误中止，避免栈溢出 |
| Newick 节点数 | 2,000,000 | Newick 读取器 | 以错误中止 |
| Newick 树数 | 100,000 | Newick 读取器 | 以错误中止 |
| 记住的对话框授权路径 | 256 | 桌面壳 | 丢弃最旧的授权 |
| 减少交叉候选子树 | 每轮 256 | 布局启发式 | 仅考察最小的 256 个含转移子树 |
| 减少交叉迭代轮数 | 8 | 布局启发式 | 无改进即提前结束 |
| 撤销历史 | 100 步 | 状态存储 | 丢弃最早一步 |
| PNG 画布 | 单边 16,384 px **且** 总面积 ≈6.7×10⁷ px | 导出 | 降低缩放并回报实际 DPI |
| 统计表格 | 前 25 行 | 右侧面板 | 按物种表与转移矩阵只列最大的 25 条；CSV 导出不截断 |
| 视口剔除 | 基因节点总数超过 1,500 时 | 画布 | 视口外的基因元素不绘制；物种管道、标签与转移弧始终绘制 |
| 细节层级 | 缩放 < 0.42× 与 < 0.16× | 画布 | 与文档大小无关：先丢标签，再丢纯事件字形 |
