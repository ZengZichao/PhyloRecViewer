## 1. 软件概述

PhyloRecViewer 是面向演化生物学研究者的**基因–物种调和（gene–species reconciliation）可视化查看器**。它原生支持 **recPhyloXML** 格式，并直接读取带 `[&&NHX]` 批注的调和基因树，无需任何前置转换脚本。软件完全离线运行，可交互式浏览大规模调和事件（物种形成、基因重复、基因丢失、水平基因转移等），并提供搜索与筛选、结果统计、转移网络、数据检查与出版级导出能力。

### 1.1 核心特性

- 离线桌面应用，数据不离开本机
- recPhyloXML 与 NHX / Newick 双格式自动识别
- 三层嵌套调和视图（基因 → 共生体 → 宿主）
- 两个调和结果的对比视图——画布默认上下分栏，可一键切换左右分栏；自动高亮不一致节点（同时比较事件类型、物种映射与转移供体 / 受体）
- 丰富的布局与样式参数实时调节（四方向、紧凑布局、分支长度等）
- 节点搜索（支持正则）、事件类型筛选、基因家族筛选、置信度区间筛选
- 统计报表（含 CSV 导出）、转移网络环形图、十六项数据检查（完整清单见[第 7.4 节](#74-检查)）
- 批量重命名标签、节点批注（含批注模式）
- 撤销 / 重做（100 步）、会话保存恢复、多标签页
- 一键导出 PNG（屏幕 2× / 300 / 600 / 1200 / 2400 / 4800 DPI 或自定义）/ SVG / PDF / 交互式 HTML / NHX；无头命令行还可导出无损的 recPhyloXML 往返格式（见[第 9.2 节](#92-数据)）
- 中英双语界面，浅色 / 深色 / 跟随系统三档主题
- 三套内置示例：完整示例、基因 / 共生体 / 宿主嵌套视图、对比示例（见[第 4.5 节](#45-装入示例数据)）

### 1.2 快速入门

1. **启动软件**：启动后显示空状态起始页——可**打开文件**、**装入示例**（三个内置示例之一）、把文件拖进窗口，或点**快捷键与帮助**先熟悉操作。
2. **打开自己的数据**：菜单 **文件 → 打开文件**（或按 `⌘O` / `Ctrl+O`），选择受支持的文件——内容为 **recPhyloXML** 的 `.recphyloxml` / `.recphylo` / `.xml` / `.phyloxml` 文件，或 `.nhx` / `.nwk` / `.newick` 基因树文件（详见[第 4.1 节](#41-打开文件)）；也可以直接把文件拖进窗口。
3. **浏览**：滚轮缩放、拖拽空白处平移、按 `F` 适应窗口。
4. **交互**：单击基因节点高亮其谱系并打开节点检查器；`Shift` + 单击添加批注；`Alt`/`⌥` 或 `⌘` + 单击内部基因节点折叠 / 展开子树；单击物种枝进行镜像。
5. **分析**：点击画布左上角 **◧** 按钮打开右侧分析面板，使用搜索、结果统计、网络与检查（详见[第 7 节](#7-右侧分析面板)）。
6. **导出**：菜单 **导出** 选择出版级 PNG / SVG / PDF / HTML，或 **NHX（扩展方言）…** 数据导出（NHX 即带 `[&&NHX]` 事件批注的 Newick 基因树）；无头命令行（`npm run cli`）还可导出无损的 recPhyloXML 往返格式（见[第 9.2 节](#92-数据)）。

> 左侧面板底部的「提示」清单与 **帮助** 菜单中的快捷键速查卡始终可用（按 `?`）。

### 1.3 术语表

| 术语 | 说明 |
|------|------|
| **调和（reconciliation）** | 基因树与物种树之间的映射，用于推断物种形成 / 基因重复 / 基因丢失 / 转移等事件 |
| **recPhyloXML** | 本软件的原生文件格式，以 `<recPhylo>` 为根元素 |
| **NHX** | 一种带批注的基因树格式（`[&&NHX]`），可承载调和事件信息 |
| **镜像** | 左右翻转某个物种子树，用于减少转移交叉；软件内部称 `swap` |
| **谱系（lineage）** | 某个基因节点从其祖先到后代的完整路径 |
| **物种管道（species tube）** | 画布上表示物种树分枝的粗线段 |
| **转移弧（transfer arc）** | 连接供体与受体的虚线箭头，表示水平基因转移 |
| **事件（event）** | 基因节点的演化事件类型，共七类（见[第 8 节](#8-图例)） |

## 2. 安装与启动

### 2.1 桌面版（推荐）

1. 从发布页（GitHub Releases）下载对应系统的安装包。
2. 安装并启动 **PhyloRecViewer**。
3. 启动后显示空状态起始页：可打开文件、装入内置示例、拖入文件或查看快捷键帮助。

| 平台 | 安装包 |
|---|---|
| macOS（Apple Silicon / Intel） | `.dmg` |
| Windows | `.exe` 安装器（或 `.msi`） |
| Linux | `.deb`（或 `.AppImage`） |

桌面窗口默认尺寸 1320×860，最小 900×600。

### 2.2 浏览器版

构建产物位于 `dist/`，请用 `npm run preview` 起本地服务后打开其打印出的 `http://localhost:4173/` 地址：产物以 ES 模块方式加载脚本，浏览器不允许在 `file://` 协议下执行模块脚本，因此直接双击打开 `dist/index.html` 只会看到空白窗口。浏览器版使用浏览器自带文件选择器与下载功能，**不支持**系统原生文件对话框与文件关联打开。其余功能（画布、分析、导出下载）与桌面版一致。

### 2.3 从源码运行（开发者）

```bash
cd PhyloRecViewer
npm install
npm run dev        # 浏览器开发服务器（Vite，http://localhost:5173）
npm run tauri dev  # 桌面（Tauri）开发模式
npm run build      # 生产构建 -> dist/
npm test           # 运行 Vitest 单元测试
npm run typecheck  # tsc -b 类型检查
npm run lint       # ESLint
npm run cli -- --help   # 无头命令行：统计 / 检查 / SVG / HTML / recPhyloXML / NHX 导出
```

前置条件：Node.js 20+、npm 9+；桌面打包还需 Rust 1.77+。

## 3. 界面总览

界面自顶向下、由左到右分为以下区域：

```
┌────── 菜单栏（MenuBar）：文件 | 导出 | 视图 | 帮助 ──────┐
│      （右侧：警告徽章 · 文件名信息 · 可拖动空白区）      │
├──────── 标签栏（TabBar）：文档标签 + 新建标签页 ─────────┤
├ 左侧面板 ─┐ ┌───── 主画布（Canvas） ─────┐ ┌─ 右侧面板 ──┐
│ 控制面板  │ │ 左上：浮动工具栏           │ │ 分析面板    │
│ 布局操作  │ │ （缩放 / 适应 / 撤销 /     │ │ 搜索        │
│ 布局参数  │ │ 批注 / 分析开关）          │ │ 结果统计    │
│ 样式      │ │ 中部：物种管道 + 基因骨架  │ │ 网络        │
│ 标签      │ │ + 转移弧 + 标签 + 批注     │ │ 检查        │
│           │ │ 左下：图例 · 右上：小地图  │ │ 批注        │
│           │ │                            │ │ （差异）    │
└───────────┘ └────────────────────────────┘ └─────────────┘
```

- **菜单栏（MenuBar）**：文件、导出、视图、帮助四个下拉菜单，「视图」右侧另有 **设置** 按钮（详见[第 12 节](#12-菜单栏参考)）。解析有警告时菜单栏会显示警告数徽章，点击它可打开「检查」面板查看全部警告。
- **标签栏（TabBar）**：多文档标签，支持新建、切换、关闭（详见 4.8）。
- **左侧面板（控制面板）**：布局操作、布局参数、样式、标签四个可折叠区块，区块之间以细分隔线分隔而非卡片（详见[第 6 节](#6-左侧控制面板)）。
- **主画布（Canvas）**：核心可视化区域。左上角为浮动工具栏（缩放、适应窗口、撤销/重做、批注模式、分析面板开关），左下角为图例，右上角为小地图（详见[第 5 节](#5-画布浏览与交互)）。
- **右侧面板（分析面板）**：搜索、结果统计、网络、检查、批注五个固定标签页；对比模式下额外出现 **差异** 标签页（详见[第 7 节](#7-右侧分析面板)）。

> 左右侧面板均可通过拖动分隔条调整宽度；点击面板顶部的 `‹` / `›` 按钮可收起 / 重新展开。未载入文档时不显示任何面板：空屏只有一个居中的起始面板（打开文件、快捷键与帮助、示例文件），载入第一个文档后左右两侧才出现。窄窗口策略在启动时判定，之后每次窗口**变窄**时重新判定：低于 1180 px 时分析面板自动收起，低于 920 px 时左侧面板也会自动收起（均可手动重新打开；只要不再跨过阈值，重新打开的面板会保持打开）。

## 4. 文件操作

### 4.1 打开文件

菜单 **文件 → 打开文件**（快捷键 `⌘O` / `Ctrl+O`）：

- **桌面版**：弹出系统原生文件选择器，可一次多选。
- **浏览器版**：弹出浏览器文件选择器。

支持的扩展名：`.recphyloxml` `.recphylo` `.xml` `.phyloxml`——它们只是**recPhyloXML 内容**的容器（普通 PhyloXML 树不是调和结果，会被拒绝）——以及 `.nhx` `.nwk` `.newick`（NHX / Newick 基因树）。格式自动识别，无需手动指定，详见[第 15 节](#15-支持的文件格式)。

打开单个文件时自动解析并渲染。若当前标签页是空白或只显示**未经编辑**的内置示例，则在当前标签打开；若标签页中的文档已被修改（或示例已被编辑过），则新建标签页以保留已有工作。

### 4.2 多文件打开：合并还是分标签

一次选择 / 拖入 **多个文件** 时，会弹出 **「你想以哪种方式打开 N 个文件？」** 对话框：

- **合并为一个文档**：以第一个文件的物种树为基准，把所有文件的基因家族合并进同一次调和；各家族按来源文件命名并用不同颜色区分。若后续文件引用了第一个物种树中不存在的物种，会计入警告。
- **每个文件一个标签页**：每个文件独立成标签页，互不影响。

合并成功后显示「已将 N 个文件合并为一个文档」提示。

### 4.3 拖放打开

把一个或多个文件 **拖拽到窗口任意位置**，出现 **「释放以打开」** 覆盖提示，松手即可打开。拖放多文件时同样会询问合并还是分标签（见 4.2）；拖放单个文件时，仅当当前标签页空白或显示**未经编辑**的内置示例时才会复用当前标签——若标签页中是已修改的文档，拖放会**新建标签页**，已有工作不会被覆盖。

### 4.4 系统关联打开（双击 / 「打开方式」）

桌面版注册了文件关联：`.recphyloxml` / `.recphylo` 与 `.xml` / `.phyloxml`（recPhyloXML），以及 `.nhx` / `.nwk` / `.newick`（NHX / Newick）。文件关联只决定用哪个程序打开文件——文件内容仍须是 recPhyloXML 或 NHX / Newick（普通 PhyloXML 树会被拒绝，见[第 15 节](#15-支持的文件格式)）。由于 `.xml` 是通用扩展名，注册后本软件可能成为其它 XML 文档的候选默认程序；如不需要，可在系统设置中取消 `.xml` 的关联。在系统文件管理器中：

- **双击**此类文件，或 **右键 → 打开方式 → PhyloRecViewer**，会用该文件启动 / 唤醒应用。
- 应用已在运行时，新文件会作为新标签页载入（macOS 通过 `open-file` 事件）。

### 4.5 装入示例数据

菜单 **文件 → 示例** 内置 3 套示例（菜单标签描述示例所含的事件，并随界面语言显示）：

| 示例 | 说明 |
|------|------|
| **完整示例**（Showcase） | 综合示例：物种形成 / 基因重复 / 基因丢失 / 基因转移 |
| **对比示例** | 同一家族的两种推断结果（自动进入对比视图） |
| **嵌套示例** | 基因 / 共生体 / 宿主三层（自动进入嵌套视图） |

装入示例后标签页会标记为示例状态；打开真实文件时该标记自动清除。空状态页与解析失败面板上也有 **装入示例** 快捷入口。

### 4.6 嵌套层（三层视图）

菜单 **文件 → + 嵌套层** 加载第二个调和文件作为**宿主（Host）层**，进入三层视图：

- 左侧画布：**基因 → 共生体**（Gene → Symbiont）
- 右侧画布：**共生体 → 宿主**（Symbiont → Host）

加载后菜单项变为 **「嵌套：<filename> ✕」**（名称超过 20 个字符时截为前 18 个字符加 `…`），点击即移除嵌套层，回到单层视图。嵌套画布的物种镜像状态独立于主画布保存（内部为 `nestedSwapped` 与 `swapped` 两套集合），同名物种不会互相影响。

> 注意：更换主文件会自动清除已加载的嵌套层与对比。嵌套文件解析出错时，画布顶部会显示黄色横幅（「嵌套文件错误：…」）。

### 4.7 对比视图

菜单 **文件 → + 对比** 加载另一份调和结果（通常用于同一基因家族的不同工具 / 参数的推断），进入对比视图：

- 两个画布，标题分别为文件名（主文档 / 对比文档）。画布默认采用**上下分栏**排布；对比状态栏中的 ⇕ / ⇔ 按钮可切换为**左右分栏**，该选择会被记住。
- 软件**自动高亮两个结果不一致的基因节点**。比较覆盖**三个维度**——末端事件类型、物种映射、转移供体 / 受体——因此仅把某个基因挪到另一物种的结果不会再得到 100% 一致。状态栏中出现「两个文件不一致的节点」色块。
- 画布下方的**状态栏**显示明细：一致率（在**所有**维度上都一致的节点数 / 可比较节点的并集）、匹配节点间的物种映射一致率，以及匹配 / 仅主文档有 / 仅对比文档有的节点数，例如 `71% 一致 · 物种一致 80% · 匹配 7 · 仅主文档有 1 · 仅对比文档有 0`。
- **联动视图** 复选框让两个画布的缩放 / 平移保持同步；取消勾选时两个画布可独立浏览。
- 对比画布拥有**独立的**镜像、折叠与家族颜色状态，与主文档互不影响——并且会一并存入会话文件（见[第 10 节](#10-会话保存与加载)）。
- 状态栏中的 ◎ / ◉ 按钮可隐藏或恢复差异高亮；右侧面板同时出现 **差异** 标签页（见 7.6）。

加载后菜单项变为 **「对比：<filename> ✕」**（名称超过 20 个字符时截为前 18 个字符加 `…`），点击移除对比。

> 注意：嵌套层与对比**互斥**，加载其一会自动清除另一个。

### 4.8 多标签页

- 菜单栏下方标签栏右侧 **＋** 按钮：新建空白标签页。
- 点击标签页切换文档；每个标签页独立保存各自的文件、镜像、折叠、家族颜色、批注、重命名、搜索条件与撤销历史。
- 悬停标签页显示 **✕** 关闭按钮。若文档包含未保存的修改（批注、镜像、颜色、重命名等），关闭未保存的文档前会弹出确认框，防止误丢工作；关闭最后一个标签页会重置为空白标签页而非退出。
- 关闭当前激活标签时，自动激活相邻标签。
- 标签栏支持键盘操作：`←` / `→` 切换，`Home` / `End` 跳至首尾，`Enter` / `空格` 激活。

## 5. 画布浏览与交互

### 5.1 画布浮动工具栏

画布**左上角**有一组浮动按钮，每个画布（主画布、嵌套画布、对比画布）都带有完整的一套，包含撤销 / 重做与分析面板开关：

| 按钮 | 功能 |
|------|------|
| `−` | 缩小（1/1.2） |
| `100%` | 当前缩放比例（实时显示） |
| `＋` | 放大（1.2×） |
| `⤢` | 适应窗口（同 `F`） |
| `↶` / `↷` | 撤销 / 重做（同 `⌘Z` / `⌘⇧Z`） |
| `✎` | **批注模式**开关（见 5.8） |
| `◧` | 打开 / 关闭右侧分析面板 |

### 5.2 缩放与平移

| 操作 | 说明 |
|------|------|
| **滚轮** | 以鼠标位置为中心缩放 |
| **拖拽空白处** | 平移画布 |
| **`⌘ +` / `⌘ =`（mac）或 `Ctrl +` / `Ctrl =`** | 放大 1.2× |
| **`⌘ -` / `Ctrl -`** | 缩小 1/1.2 |
| **`F`** 或 `⤢` 按钮 | 适应窗口 |
| **缩放比例显示** | 浮动工具栏内实时百分比 |

缩放范围 **3% – 1000%**。缩放级别驱动细节层次（LOD）：低于 **0.42×** 时丢弃纯事件字形（基因重复方形、基因丢失叉形、转移与物种形成标记），物种标签、基因标签与基因描边仍会绘制；低于 **0.16×** 时标签与描边也不再绘制。折叠楔形与末端节点在任意缩放级别都绘制，因此树的结构始终可读。数据量大时窗口右上角会短暂显示「渲染中…」指示。

### 5.3 适应窗口

按 **F** 或点击 `⤢` 按钮，画布自动缩放并居中完整图谱。载入新文件、切换标签或改变树朝向时会自动适应；图面因参数变化显著增大时（如调大层级高度）也会自动重新适应，避免内容溢出视口。

### 5.4 小地图

左侧面板 **布局参数 → 小地图** 开关可开启 / 关闭小地图（画布**右上角**，168×120）：

- 缩略显示物种骨架与当前视口（高亮矩形）。
- 在小地图内 **拖拽** 可平移主画布视口；滚轮事件被小地图独占，不会触发主画布缩放。
- **键盘**：小地图可获得焦点——方向键逐步平移视口，`Enter` / `空格` 将视图重新居中到整幅图。

### 5.5 基因节点交互

| 操作 | 效果 |
|------|------|
| **悬停** | 工具提示：基因名 / 事件类型 @ 物种 |
| **单击** | 高亮该节点的**谱系**（祖先 → 后代整条路径）**并打开节点检查器**（见下），其余节点变暗；再次单击空白处取消 |
| **`Shift` + 单击** | 打开**批注编辑器**（见 5.8） |
| **`Alt` / `⌥` 或 `⌘` + 单击内部节点** | 折叠 / 展开该子树（见 5.7） |
| **单击空白处** | 清除谱系高亮，回到搜索 / 筛选的变暗状态 |

高亮优先级：手动点击的谱系 > 搜索 / 筛选变暗。

**节点检查器**：单击基因节点（或转移弧）会打开一张可停靠的详情卡片，展示该节点的科学细节——物种、所属家族、转移供体 / 受体、时间片、事件置信度或演化支支持度、枝长、父 / 子节点数与用户批注——并提供**定位**、**添加批注**、**复制详情**三个操作。节点工具提示与转移弧工具提示（供体 → 受体、时间片、置信度）无需点击即可快速查看。

### 5.6 物种枝交互（镜像）

- **单击物种枝**（有子节点的物种）：**镜像该子树**（即切换镜像），再次单击恢复。
- 用途：**减少转移交叉**——把容易产生交叉的子树翻到另一侧。也可以用左侧面板的**减少交叉**按钮自动优化。
- 镜像状态计入撤销 / 重做历史。
- 三层视图中，左右画布的镜像状态**独立**保存，同名物种不会串扰。

### 5.7 折叠 / 展开

- **`Alt` / `⌥` + 单击内部基因节点**：折叠 / 展开该子树；`⌘`（macOS 的 Cmd，其他平台的 Super/Win）+ 单击同样有效。
- 折叠后的子树显示为**楔形（wedge）**，指向现存基因方向并标明其数量，如 `折叠分支 · 12 个现存基因`。
- 再次 `Alt` / `⌥` 或 `⌘` 单击即可展开；折叠状态计入撤销 / 重做历史；悬停楔形会提示「Alt/⌥ 或 ⌘ 单击展开」。

### 5.8 批注

两种方式添加 / 编辑批注：

- **`Shift` + 单击**基因节点，直接弹出批注编辑器；
- 或点击浮动工具栏 **✎ 进入批注模式**（按钮高亮），此后**单击**任意基因节点即可批注；再次点击 `✎` 退出批注模式。

批注编辑器：输入文字、选择颜色后点**保存**（或 `⌘Enter`），节点显示**彩色圆环 + 文字**；可**删除**或**取消**（`Esc`）。已保存的批注集中在右侧面板 **批注** 标签页中统一管理（见 7.5）。批注保存在会话文件中（见[第 10 节](#10-会话保存与加载)）。

### 5.9 画布上重命名标签

**单击**画布上的任一名称标签（物种名，或带名称的基因标签；光标会变为手型），出现内联输入框：`Enter` 确认、`Esc` 取消、失焦提交。重命名属于可撤销操作，也可在左侧面板 **标签** 区块中批量执行或重置（见 6.4）。

## 6. 左侧控制面板

左侧面板标题为**控制面板**，含四个可折叠区块（折叠状态记忆在本地，可点击区块标题右侧图钉固定展开）；底部有**提示**清单，汇总画布操作要点。

### 6.1 布局操作

| 按钮 | 说明 |
|------|------|
| **减少交叉** | 以启发式缩短转移弧：自动镜像子树（同时优化主画布与嵌套画布）。目标函数是供体—受体的叶序距离之和，它是交叉数的代理而非交叉计数；最多迭代 8 轮、每轮最多考察 256 个候选子树，因此超大且富含转移的物种树只能被部分优化 |
| **重置镜像** | 清除所有镜像 |
| **全部重置** | 将所有布局与样式参数恢复为默认值 |

### 6.2 布局参数

| 参数 | 范围 | 说明 |
|------|------|------|
| **显示图例** | 开/关 | 在画布上显示图例，并在导出图像时一并包含 |
| **小地图** | 开/关 | 显示 / 隐藏右上角小地图 |
| **树朝向** | 根在上 / 根在下 / 根在左 / 根在右 | 四向单选按钮 |
| **层级高度** | 40–220 | 相邻物种层之间的距离 |
| **基因间距** | 8–42 | 相邻基因树之间的水平间距 |
| **物种间距** | 8–70 | 相邻物种叶节点之间的间距 |
| **物种枝粗细** | 12–80 | 物种管道的粗细 |
| **基因树粗细** | 1–5（步长 0.2） | 基因骨架线的粗细 |
| **末端对齐** | 开/关 | 现存物种末端对齐到同一基准线（超度量观感）。注意：开启 **分支长度** 时该选项会把末端按枝长推算的位置「压平」——如需读取真实时间比例，请关闭它 |
| **分支长度** | 开/关 | **物种树**按分支长度布局（而非等深）；基因树不受影响。缺失的枝长按 0 计，负值枝长绘图时按 0 处理（两者都会被数据检查报告） |
| **紧凑布局** | 开/关 | 相邻子树尽量靠拢（轮廓法），而非固定宽度叶槽 |
| **重复事件居中** | 开/关 | 基因重复节点放在物种分支**中点**（否则更靠近祖先端） |

### 6.3 样式

| 参数 | 范围 | 说明 |
|------|------|------|
| **曲线分支** | 开/关 | 物种枝为圆角曲线还是直角折线 |
| **符号大小** | 4–16 | 事件符号大小 |
| **转移弧度** | 0–0.5（步长 0.02） | 转移弧的弯曲程度 |
| **基因描边** | 开/关 | 基因线加浅色描边（halo），提升在物种管道上的对比度 |
| **事件符号** | 开/关 | 是否显示事件符号（基因重复方块、基因丢失叉号等） |
| **支持度** | 开/关 | 在节点旁显示事件置信度**与**演化支 / 节点支持度（优先显示末端事件的置信度，否则显示演化支支持度；物种内部节点名也会附带 bootstrap / posterior 值）。数值同样出现在节点工具提示与节点检查器中 |
| **管道渐变** | 开/关 | 物种管道使用渐变色填充 |
| **重叠拷贝数（泳道）热力图** | 开/关 | 物种管道按其内部排布的基因 lane 数（布局引擎的并发泳道数）热力着色。这是布局量而非基因拷贝数：不含基因丢失的每物种基因计数在统计面板中单列为 **非丢失谱系** |

### 6.4 标签与批量重命名

以下三类标签可分别开关，并各自设置样式：

- **物种名**
- **末端基因名**
- **基因内部节点名称**

每类标签可独立调节：**角度**（−90°–90°，步长 5°）、**字号**（6–28）、**加粗**、**斜体**、**偏移**（−40–140）、**对齐**（自动 / 左对齐 / 居中对齐 / 右对齐）。

**完整标签**（开/关）位于三类标签开关之下，用于关闭标签截断。默认情况下，超过 48 个字符的基因标签——末端基因名、基因内部节点名称与折叠分支标签——在画布与导出图像中都会以前 47 个字符加 `…` 绘制，因为完整长度会溢出布局为标签预留的层级并与相邻标签碰撞。完整文本始终保留在节点工具提示与无障碍标签中，因此不开启也不会丢失信息；需要让长序列名在图面中完整出现时再开启（此时可能发生重叠）。

区块底部还有：

- **批量重命名标签**：打开对话框，支持正则表达式；**查找** / **替换为** 输入框；**范围**可选物种标签 / 基因标签 / 全部标签；点**应用**生效。
- **重置标签**：存在重命名记录时显示，一键恢复原始名称。
- 画布上**单击**单个标签可就地重命名（见 5.9）。

## 7. 右侧分析面板

点击浮动工具栏 **◧**（或 `Esc` 关闭后用 `⌘F` 直接跳到搜索标签页）打开 / 关闭右侧分析面板。面板含五个固定标签页，对比模式下额外出现第六个：

**搜索 / 结果统计 / 网络 / 检查 / 批注 /（差异）**

> 键盘操作：标签栏可用 `←` / `→`、`Home` / `End` 切换。

### 7.1 搜索

- **搜索框**：输入基因名或物种名；勾选**正则表达式**启用正则搜索。
- 按 `Enter` 跳至下一个匹配，`Shift + Enter` 跳至上一个；也可以用 **下一个 / 上一个** 按钮，每次跳转将主画布**居中**到该节点。匹配计数显示如 `12 个匹配`，无匹配时显示「无匹配」。
- **按事件类型**：勾选物种形成 / 基因重复 / 基因丢失 / 基因转移 / 现存基因五类，仅显示勾选类型相关的节点。
- **按基因家族**：多基因树时，每个家族前带颜色色块，勾选切换显示。
- **置信度区间**：两个滑块设定置信度（0–1）范围，以筛除低置信度节点。
- **仅显示匹配**：开启后只渲染匹配节点（默认将不匹配节点变暗至透明度 0.12）。
- **清除筛选**：一键清空搜索词、正则开关、事件筛选、家族筛选与置信度区间。

### 7.2 结果统计

- **汇总**：两列八格的计数表——节点、末端节点、内部节点、基因树，以及物种形成 / 基因重复 / 基因丢失 / 转移四类事件各自的计数。转移到达属于叠加事件，不计入构成占比，但仍计入汇总。**导出 CSV** 位于该区块标题行右侧（见本节末尾）。
- **事件分布**：物种形成 / 基因重复 / 基因丢失 / 转移供体 / 二叉输出 / 现存基因的占比视图。
- **按基因家族**（多基因家族时）：每个家族的事件计数表。
- **转移矩阵**：供体 → 受体的转移次数表（前 25 条），列为供体 / 受体 / 次数。
- **按物种（前 25）**：每个物种的 **非丢失谱系**（该物种携带的基因谱系数，不含基因丢失）、物种形成、基因重复、基因丢失、转移供体、二叉输出与现存基因计数（前 25 个物种）。每物种的转入计数在 **转入事件** 列中单列，与上述供体侧事件分列——CSV 导出中该列保留机器可读名 `transfer_arrivals`（见下）。
- **节点**：全部节点明细表（编号、名称、类型、事件、物种，载入多个基因树时另有「基因树」列）。节点分类为**末端节点 / 基因丢失 / 内部节点**——基因丢失不再并入「内部节点」——排序为先现存基因、再基因丢失、最后内部事件。表格最多显示 500 行，超出时显示「前 X / 共 Y · 表格已截断（前 500 行）」。
- **导出 CSV**：将统计结果导出为 `<filename>-stats.csv`，使用**稳定的英文列名**并带 **UTF-8 BOM**（Windows Excel 打开物种名不乱码），文件头部含来源信息（源文件、软件版本、导出时间）。分区依次为 `families`、`transfer_matrix`、`species`（含 `transfer_arrivals` 列；存在未分配物种的节点时会追加一行，其物种列为字面量 `NA`（界面上同一行显示为「（无物种）」））与 `nodes`（额外包含 `donors`、`recipients`、`time_slice`、`confidence`、`branch_length` 列）。CSV 导出不截断。

### 7.3 网络

以**环形图**展示供体 → 受体的转移关系：

- 节点 = 物种，大小按涉及的转移数加权；箭头 = 转移方向，粗细表示次数。
- **悬停**节点可聚焦其相关转移，其余变暗。
- 自转移（供体 = 受体）显示为小圆环。
- 无转移事件时显示「无转移事件」。

### 7.4 检查

对载入数据做十六项结构检查。面板顶部先给结论与 **导出质量报告**，其下只列出**未通过**的检查项——每项含计数、问题描述，以及一键跳到第一个异常节点——末尾再以紧凑的**通过**列表收尾，因此单个异常不会被十五个通过项淹没。下表是完整清单：

| 检查项（名称） | 发现的问题 |
|----------------|-----------|
| 物种引用有效 | 基因引用了物种树中不存在的物种 |
| 物种命名唯一 | 物种树中存在重名物种 |
| 基因均有物种归属 | 基因节点未分配物种 |
| 现存基因落在叶物种 | 现存基因位于内部（非叶）物种 |
| 转移供体配对完整 | 转移供体缺少转移到达子节点 |
| 转移到达有供体谱系 | 转移到达缺少供体谱系 |
| 转移到达位于供体之下 | 转移到达的父节点不是转移供体或二叉输出供体 |
| 二叉输出供体已配对 | 二叉输出供体缺少转移到达子节点 |
| 基因丢失 / 现存基因事件为末端节点 | `loss`/`leaf`（末端）节点带有子节点 |
| 物种形成 / 基因重复应为二叉 | 物种形成或重复节点不是二叉 |
| 转移沿时间正向 | 转移到达进入某物种的祖先（时间倒流）——记为错误；两侧都有时间片时会直接比较数值 |
| 同物种内转移 | 转移到达其出发的同一物种——可能是预期的种内基因流，单列报告（这是模型问题，不是时间方向错误） |
| 转移时间不可判定 | 供体或到达事件缺少时间片，且两个物种不构成祖先关系，因此无法判断时间方向（拓扑深度不是时间）——此时报告「转移时间不可判定」而非静默通过 |
| 置信度疑似 0–100 刻度 | 某个置信度 / 支持度大于 1 且不超过 100——可能是百分数，而置信度筛选按 0–1 解释 |
| 负值 / 非法枝长 | 某个枝长为负或非有限值；绘图时按 0 处理 |
| 垂直边跨到无关演化支 | 一条非转移的基因边在无关物种之间跳转——没有转移时不可能发生，请检查各事件记录的物种 |

全部通过时顶部显示**「全部数据检查通过」**；有问题时显示「M 项检查中 N 项异常」，并先列出未通过的检查项。

### 7.5 批注

集中管理当前文档的全部批注：列出每个批注的节点与内容，可跳转、编辑或删除；无批注时提示「还没有批注。Shift 点击基因节点（或使用批注模式）添加一条。」

### 7.6 差异（对比模式）

仅在对比视图（4.7）下出现：

- 以一张可点击的表格列出**两个文件不一致的节点**——在任一比较维度（事件类型、物种映射或转移供体 / 受体）上不同、或只在其中一个文件中存在的节点；事件列与物种列各按 **主文档 / 对比文档** 成对给出，点击某行会在主画布上定位该节点。
- 对比**状态栏**（4.7）给出汇总数字：一致率、物种映射一致率、匹配 / 仅主文档有 / 仅对比文档有的计数；其中的 ◎ / ◉ 按钮可隐藏或恢复差异高亮。

## 9. 导出

菜单 **导出**（无内容时置灰；快捷键 `⌘E` / `Ctrl+E` 直接导出 PNG）：

### 9.1 导出图像

| 格式 | 说明 |
|------|------|
| **PNG** | 位图；分辨率在菜单内选择：**屏幕 2×（192 DPI）/ 300 / 600 / 1200 / 2400 / 4800 DPI**，适合幻灯片与文档。当图形过大时，按两条平台画布上限中**更严格**的一条自动降级——最长边 16,384 px，且总像素不超过 16,384²/4 ≈ 6.7×10⁷；对接近正方形的图幅，总面积限制会先生效（约单边 8,192 px）。系统会以提示告知实际使用的 DPI |
| **SVG** | 矢量图，无限缩放，适合进一步编辑 |
| **PDF** | 矢量页面，适合论文插图 |
| **HTML** | 交互式 HTML（保留缩放 / 平移 / 悬停提示），可离线分享 |

- 嵌套 / 对比视图会将**多个画布导出到同一张图 / 页**，排列方式与屏幕一致（默认上下分栏；开启切换后为左右分栏）。
- 导出文件名默认为源文件名去扩展名（特殊字符替换为 `_`），如 `myfile.png`。
- 导出中菜单显示「导出…」，完成后弹出「已导出」提示，失败时提示「导出失败」及原因。

### 9.2 数据

- **NHX（扩展方言）…**：导出菜单「数据」分区中的这一项把当前调和结果写为带事件批注的 NHX 基因树（NHX 即带 `[&&NHX]` 批注的 Newick 树，菜单中没有单独的 Newick 项），文件名 `<filename>.nhx`。NHX 是本软件的**扩展方言**，不是通用交换格式：导出会写入**全部转移到达**（首个为 `TB=`，同节点其余到达依次写为 `TB2=`、`TB3=` 等，不设上限）、`timeSlice`（`TS=`）、事件置信度（`CN=`）、节点支持度（`B=`），枝长同时写入标准 Newick 的 `:length` 与冗余的 `BL=` 标签；节点自身没有物种时，其 `S=` 标签取自最近的一个带物种的祖先。但它仍会丢失**物种树本身**（NHX 依靠 `S=` 标签重建）、**物种枝长**、**基因树名称**，以及**从未被任何基因树取样的物种**。
- **recPhyloXML（无损往返）**：无头命令行可将调和结果原样写回 recPhyloXML，物种树（含枝长）、全部事件、同一节点的多个 `transferBack` 到达、`timeSlice` 与置信度全部保留（`npm run cli -- export --session <file>.rpvsession.json --out <file>.recphyloxml`；该命令行还可导出 SVG / HTML / NHX 并输出统计 / 检查报告——它不能导出的内容见[第 18 节](#18-已知局限)）。

> 桌面版通过系统保存对话框选择路径；浏览器版直接下载到默认下载目录。

## 10. 会话保存与加载

菜单 **文件 → 会话另存为…**（`⌘S` / `Ctrl+S`）：保存当前会话为 `.rpvsession.json`；**文件 → 打开会话…**：从 `.rpvsession.json` 恢复。

会话为纯 JSON（其 schema 版本标记为 `CURRENT_SESSION_VERSION`——本构建写入 **schema v2**），包含：

- 源文件内容（`xml`）及嵌套层 / 对比的源文件与文件名
- 合并文档的**完整来源文件列表**（`sourceFiles`），重新载入时可原样重建合并结果——菜单载入与启动恢复共用同一条恢复路径，合并的全部基因家族都会恢复
- 全部布局参数、渲染参数、主题；自 schema v2 起，**每个后台标签页还保存自己的布局 / 样式选项**
- 物种镜像集合（主画布、嵌套画布与**对比画布**分开）、折叠集合——包括对比画布的 `compareSwapped` / `compareCollapsed` / `compareGeneColors`
- 每个基因树的颜色、每个节点的批注、标签重命名记录——既按标签文本、也按**节点 id**（`labelOverridesById`）保存，因此可以只重命名同名的多个标签之一
- 当前的**搜索与筛选条件**（`searchQuery`、`searchRegex`、`eventFilter`、`familyFilter`、`confidenceMin` / `confidenceMax`，以及 `onlyMatches` 开关）
- **其余所有打开标签页的快照**（`tabs`）与其中处于激活状态的标签（`activeTabIndex`），保存并重新载入即可恢复整个会话，而不只是当前文档

**不保存的内容**：每个画布的缩放 / 平移相机状态有意不存入会话（也不存入自动保存）——恢复后的视图会重新适应内容，只有布局 / 样式 / 镜像 / 折叠状态会被还原。

**兼容性**：字段缺失的会话文件按默认值打开；schema 版本标记高于本构建的会话文件会被拒绝，并提示「此会话由较新版本的 PhyloRecViewer（vN）创建；请更新后再打开。」缺少 `xml` 字段的 JSON 会被拒绝，提示「不是 PhyloRecViewer 会话文件。」

**自动保存与启动恢复**：会话约每秒自动保存一次（防抖；内容未变化时不重写），窗口关闭时 `beforeunload` / `pagehide` 会再补写一次，因此正常关窗不会丢最后几秒的修改。启动时软件不再静默恢复，而是**询问**：弹出标题为**「恢复上次会话？」**的对话框，可点击**恢复**（提示框显示快照保存时间）或**从空白开始**（丢弃快照）。若快照无法恢复——例如由更新版本的应用写入——它会被**隔离**：原样保留并提示，而不是删除，其内容仍可在本地存储中找回。

> 会话保存的是源文件内容与视图状态，**不**包含导出图像，因此文件小、适合长期归档。

## 15. 支持的文件格式

软件自动检测格式，无需手动指定：

| 格式 | 扩展名 | 说明 |
|------|--------|------|
| **recPhyloXML** | `.recphyloxml` `.recphylo` `.xml` `.phyloxml` | 原生格式，根元素 `<recPhylo>`。这些扩展名只是容器——文件内容必须是 recPhyloXML |
| **NHX** | `.nhx` `.nwk` `.newick` | 调和基因树（含 `[&&NHX]` 批注） |
| **Newick** | `.nwk` `.newick` | 系统发育树（经 NHX 解析器） |

> **普通 PhyloXML 不受支持**：不含 `<recPhylo>` 内容的 `<phyloxml>` 文档不是调和结果，解析器会拒绝它（「未找到 `<recPhylo>` 根元素」）。请先用调和工具（Ancestors、ALE、Ranger-DTL、GeneRax 等）生成调和结果。

**检测逻辑**：先检查文件前 8000 字符是否包含 `<recPhylo` 或 `[&&NHX]` / Newick 语句 / 以 `(` 开头；否则按扩展名判断；默认回退到 recPhyloXML。

**NHX 标签方言**：解析器识别 `S=`（节点所属物种；`SP=` 作为别名同样接受）、`D=`（基因重复）、`L=`（基因丢失）、`BO=`（转移供体）、`BC=`（二叉输出）、`TB=`（转移到达；导出器把同一节点的其余到达依次编号为 `TB2=`、`TB3=` 等，不设上限，解析器全部识别）、`TS=`（时间片）、`CN=`（事件置信度）、`B=`（演化支支持度）与 `BL=`（基因树枝长，与标准 Newick 的 `:length` 冗余）。不带任何事件标签的节点按结构回退为现存基因 / 物种形成；同一节点上多个事件标签冲突时，采用与 recPhyloXML 相同的优先级（基因重复 > 基因丢失 > 转移供体 > 二叉输出），并给出点名该冲突的警告。其余标签键仍留在文件中，但不参与建模，软件会以警告列出被丢弃的键名，不做静默丢失。

**多文件合并**：见 4.2——以第一个文件的物种树为基准合并基因家族，缺失物种计入警告。

**桌面版文件关联**：安装后双击 `.recphyloxml` / `.recphylo` 或 `.nhx` / `.nwk` / `.newick` 即用本软件打开（见 4.4）。

## 17. 常见问题与排错

### Q1 打开文件报错「无法解析该文件」

- 确认文件是 **recPhyloXML**（根元素 `<recPhylo>`）或 **NHX** 格式的调和结果。
- 普通 Newick / PhyloXML 系统发育树（无调和事件批注）无法直接可视化——需先由 Ancestors、ALE、Cogent 等工具生成调和结果。
- 检查文件编码是否为 UTF-8、文件是否完整未截断。
- 失败面板上可直接**返回上一份**文档或**装入示例**继续工作。

### Q2 嵌套层或对比加载失败

- 嵌套与对比**互斥**：加载其一会自动清除另一个，属正常行为。
- 更换主文件会自动清除嵌套层与对比。
- 嵌套 / 对比文件独立解析，错误以黄色横幅显示在画布顶部（如「嵌套文件错误：…」）。

### Q3 转移交叉较多、图面杂乱

- 左侧面板 **减少交叉** 自动优化镜像（同时优化嵌套画布）。
- 手动 **单击物种枝** 逐枝镜像。
- 开启 **紧凑布局** 使子树靠拢。
- 调大 **转移弧度**，便于辨识转移弧的起止。

### Q4 导出图像模糊 / 分辨率不够

- 论文插图优先用矢量格式 **SVG / PDF**。
- **PNG** 在 **导出菜单 → PNG 分辨率（DPI）** 或 **设置** 中选择 300 / 600 / 1200 / 2400 / 4800 DPI；自定义分辨率仅在导出菜单的数字输入框中提供，**设置** 内没有自定义档。

### Q5 会话文件打不开

- 确认是 `.rpvsession.json` 且为合法 JSON。
- 若由更新版本生成，旧版本会提示「请更新后再打开」，请更新软件。
- 缺少 `xml` 字段的 JSON 会被拒绝，提示「不是 PhyloRecViewer 会话文件。」

### Q6 如何批量导入多个基因家族

- 文件选择器中**多选**多个文件（或拖放多个文件），在弹窗中选择**合并为一个文档**。
- 软件以第一个文件的物种树为基准合并；若选择**每个文件一个标签页**则互不合并。

### Q7 浏览器版与桌面版差异

| 功能 | 桌面版 | 浏览器版 |
|------|--------|----------|
| 文件对话框 | 系统原生 | 浏览器默认 |
| 文件关联打开 | 支持 | 不支持 |
| 保存路径 | 可选路径 | 下载到默认目录 |
| 离线能力 | 完全离线 | 首次加载后离线 |

### Q8 误关了带批注的标签页怎么办

关闭含未保存批注 / 镜像 / 颜色的标签时会弹出确认框（「确定关闭吗？」）；若已保存过会话，可通过 **文件 → 打开会话…** 恢复。此外，会话自动保存会对**所有打开的标签页**（而非仅当前标签）约每秒快照一次，并在窗口关闭时补写一次，因此应用意外退出后重新启动时，软件会**询问是否恢复**（对话框标题**「恢复上次会话？」**，按钮**恢复** / **从空白开始**），确认后每个标签页的文档与视图状态都会一并恢复。

## 18. 已知局限

- **无 XSD 校验**：recPhyloXML 文件按结构解析，不做官方 schema 校验；数据检查（7.4）能发现常见错误，但不能替代 schema 校验器。
- **解析器诊断以英文为规范形式**：界面会通过 `i18nDiagnostics.ts` 翻译已知消息；没有对应译文的诊断仍以英文显示。
- **缩放 / 平移相机不保存**：会话与自动保存都不记录每个画布的缩放 / 平移状态；恢复后的视图会重新适应内容。
- **PDF 字体嵌入依赖环境**：PDF 为矢量，文字使用转换器可用的字体嵌入；仅当转换器报错时才回退为整页位图。
- **无头命令行（`npm run cli`）可导出 SVG / HTML / recPhyloXML / NHX 与 JSON 统计 + 检查报告，但不能导出 PNG**（位图需要浏览器画布）。
- **对比的「一致」只覆盖事件类型 + 物种映射 + 转移供体 / 受体——不覆盖拓扑与支持度**：节点按基因 / 家族名匹配（未命名演化支按叶集合匹配），重命名的演化支会计为不一致，且不比较演化支支持度差异。

## 19. 附录

### A. 软件架构（供开发者参考）

- 前端：React 18 + TypeScript（严格模式）+ Vite + Zustand（状态管理）+ d3-zoom / d3-selection + SVG 渲染
- 桌面壳：Tauri 2（Rust）——原生文件对话框、文件关联、`open-file` 事件
- 解析器：`fast-xml-parser`（recPhyloXML）+ 自研 NHX / Newick 解析
- 布局：六步布局流水线（物种布点 → 基因嵌入 → 转移弧 → 优化）
- 导出：`jspdf` + `svg2pdf.js`（PDF）、原生 SVG / PNG 序列化、自研交互式 HTML 导出
- 测试：Vitest（覆盖解析、布局、统计、校验、会话等模块）

### C. 会话文件字段

`version`（会话 schema 版本标记——本构建为 v2）、`fileName`、`xml`、`sourceFiles`（合并文档的完整文件列表）、`nestedName` / `nestedXml`、`compareName` / `compareXml`、`layoutOptions`、`renderOptions`、`themeId`、`swapped`、`nestedSwapped`、`compareSwapped` / `compareCollapsed` / `compareGeneColors`（对比画布的独立状态，v2）、`collapsed`、`geneColors`、`annotations`、`labelOverrides`、`labelOverridesById`（按节点 id 的重命名，v2）、`tabs`（其余每个已打开标签页的快照，各含自己的 `layoutOptions` / `renderOptions`，v2）、`activeTabIndex`，以及搜索与筛选条件 `searchQuery`、`searchRegex`、`onlyMatches`（v2）、`eventFilter`、`familyFilter`、`confidenceMin`、`confidenceMax`。各画布的缩放 / 平移相机不在文件之内。

### D. 实际上限

以下为代码中的硬性限制，不是配置建议；触及时会给出可读错误而非静默截断。

| 限制项 | 数值 | 作用位置 | 超限行为 |
|---|---:|---|---|
| 打开文件大小上限 | 64 MiB | 原生打开对话框与系统关联打开 | 拒绝读取并提示上限 |
| 演化支嵌套深度 | 1,000 | recPhyloXML、NHX 与 Newick 读取器 | 以「嵌套过深」错误中止，避免栈溢出 |
| Newick 节点数 | 2,000,000 | Newick 读取器 | 以错误中止 |
| Newick 树数 | 100,000 | Newick 读取器 | 以错误中止 |
| 记住的对话框授权路径 | 256 | 桌面壳 | 丢弃最旧的授权 |
| 减少交叉候选子树 | 每轮 256 | 布局启发式 | 仅考察最小的 256 个含转移子树 |
| 减少交叉迭代轮数 | 8 | 布局启发式 | 无改进即提前结束 |
| 撤销历史 | 100 步 | 状态存储 | 丢弃最早一步 |
| PNG 画布 | 单边 16,384 px **且** 总面积 ≈6.7×10⁷ px | 导出 | 降低缩放并回报实际 DPI |
| 统计表格 | 前 25 行；节点表 500 行 | 右侧面板 | 按物种表与转移矩阵只列最大的 25 条；节点明细表最多 500 行并提示截断；CSV 导出不截断 |
| 视口剔除 | 基因节点总数超过 1,500 时 | 画布 | 视口外的基因元素不绘制；物种管道、标签与转移弧始终绘制 |
| 细节层级 | 缩放 < 0.42× 与 < 0.16× | 画布 | 与文档大小无关：低于 0.42× 先丢纯事件字形；低于 0.16× 再丢全部标签与基因描边 |
